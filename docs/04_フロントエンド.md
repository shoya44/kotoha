# 04 フロントエンド

会話画面（`serve/static/`）とデスクトップの姿（`mascot/`）とタスクトレイ（`tray.py`）。どれも**器**なので、考えることも決めることもしません。

| 器 | 何 | どこで | 脳とのつながり |
|---|---|---|---|
| 会話画面 | 素の HTML / CSS / JS。PWA としてホーム画面にも置ける | 家のブラウザ、iPhone（Tailscale 経由） | HTTP ＋ SSE |
| デスクトップの姿 | 枠なしウィンドウの立ち絵とふきだし | 家のPCの画面 | SSE（ほかの器と同じ扱い） |
| タスクトレイ | 起動・見張り・メニュー。シングルクリックで姿を出し、ダブルクリックで会話画面 | 家のPC | 子プロセスとして脳と姿を起こす |

## UI方針

- **iPhone を先に考える。** 家では会話画面をPWAとしてホーム画面に置き、外からは Tailscale 経由で同じものを開きます
- **片手で戻れるように、階層は1段まで。** 設定シートの中で画面を差し替え、それ以上は潜りません
- **押し間違いで走らせたくない操作は、もう一度押させる**（「入れ直す」「消す」など。ラベルが変わって確認待ちになる）
- **器に状態を持たせない。** 会話の状態・機嫌・実体の居場所はすべて脳が持ちます。ブラウザに置くのは、合言葉・音量・時刻表示の好みのような**その端末だけの都合**（`localStorage`）
- 素の HTML / CSS / JavaScript。ビルド工程はありません

## 画面遷移

```
  合言葉の入口（gate）
        │ 合言葉が通る
        ▼
  会話画面（appShell）────────────────┐
   ├ 立ち絵・様子・モード表示         │ 歯車
   ├ 履歴（さかのぼり／最下部へ戻る） │
   ├ 入力欄・送信・電話ボタン         ▼
   └ 長押しメニュー        設定シート（1段だけ潜る）
                             ├ main       表示・声・通知・通話・再起動・合言葉
                             ├ memories   記憶の一覧（意味／出来事）
                             │   └ memory 1件の中身（直す・ピン留め・消す）
                             ├ reminders  預かっている頼まれごと
                             ├ diary      ことはの日記（新しい順）
                             ├ prompts    固定ルール・人格・整理の指示（直す／戻す）
                             ├ machine    PCの様子
                             └ settings   設定の変更
```

- 電話ボタンを押すと**通話**に入ります。聞き取り中はマイクを開き、読み上げ中は閉じます（スピーカーでも自分の声を拾わないため）
- 通話は**姿のあるところでしか始まりません**。ほかの器へ実体が移ったら、そこで切れます

## 脳から受け取るもの（SSE）

`GET /api/presence/stream` を開きっぱなしにして、脳からの合図を受けます。

| 合図 | 中身 |
|---|---|
| 実体の移動 | いまどの器に姿があるか。自分でなければ、姿を消して「どこに居るか」を出す |
| 姿の更新 | 時間帯・機嫌で変わる立ち絵、最後に話してからの経過 |
| 発言 | ことはからのひとこと（ふきだし） |
| 通話の状態 | 始まった・終わった |

画面を閉じる・裏に回るときは `POST /api/presence/bye` を送ります（`sendBeacon` を使うので、見出しを付けられず合言葉はURLに載せます）。

## 返事の出し方

**返事は、文ごとの吹き出しに分けて出します。** 全文が一度に出ると、書き置きを読んでいるように見えるためです。

```
返事が届く ──> 1つ目の文をすぐ出す ──> 打っている印（…）──> 長さぶん待つ ──> 次の文
```

- 待つ長さは文字数から決めます（1字45ms、0.35〜1.5秒）。人は長い文ほど打つのに時間がかかります
- 3つまでにしか割りません。細切れは、かえってせわしない
- 6字未満の文（「明日やる。」）は前につなぎます。ひと息で打てる長さは、分けても間が生まれません
- **分けるのは見た目だけ**です。脳には1つの返事のままで、履歴を読み直すと1つの吹き出しに戻ります
- 声は分けません。最初の吹き出しと同時に、返事ぜんぶを読み始めます

## 読み上げ

```
文が決まる ──> すぐ合成を始める（先読み）──> 行列に並べる ──> 前の文が鳴り終わったら鳴らす
```

- **間つなぎも同じ行列に並べます。** 別々に鳴らすと、流しながら喋るときに声が重なるためです
- 文の切れ目で分けて合成します（全部を1回で作るより、最初の声が早く出る）。短すぎる断片は前につなぎます（細切れは間延びする）
- 通話中は、設定で声を切っていても鳴らします
- **どんな声にするかは脳が決めます。** 器が送るのは文だけで、機嫌ぶんの話速・音高・抑揚は `/api/speak` の側で乗ります（`serve/voice.py` の `MOOD_VOICE`）
- 間つなぎだけは `plain` を付けて**素の声**で作ります。通話の初めに一度作って使い回すので、そのときの機嫌が終わりまで残ってしまうためです

## デスクトップの姿（mascot）

タスクトレイから起動する別プロセスです。`ctypes` で枠なしのウィンドウを作り、PNGは自前のデコーダで読みます（依存を増やさないため）。

- 脳とは同じ SSE でつながり、**ほかの器と同じ扱い**を受けます
- クリックで会話画面を開き、ことはが何か言えばふきだしが出ます
- 右クリックの「しまう」で消えます。**戻すのはトレイのシングルクリックか、トレイメニューの「姿を出す」**（`tray.Figure.show`）。しまうと見張りも終わるので、ここ以外に戻る道はありません
- トレイはダブルクリックの前にもシングルの合図を受けるので、シングルは OS のダブルクリック間隔だけ待ってから決めます（`tray.TIMER_CLICK`）

## 額縁

タブレットを「暇な時間の居場所」として登録し「額縁表示」を選ぶと、履歴を畳んで姿を大きく出します。**入力欄と電話ボタンは会話画面のまま残る**ので、額縁のまま話しかけたり通話したりできます。返事は畳んだ履歴と、姿の下のひとこと（`#frameBubble`）の両方に出ます。「履歴を見る」で会話画面へ、見出しの「額縁に戻る」で額縁へ戻ります。ことはがほかの器に居るあいだは、置き手紙と「こっちに呼ぶ」の立て札が出ます。
- 席にいるかどうか（最後の操作からの時間）を見て、**居ないなら姿ではなく通知へ回します**
- ふきだしは**姿のいる画面の中**に置きます（`window.work_area_at`）。主画面の広さで収めていたころは、サブディスプレイへ運ぶとふきだしだけ主画面に置き去りになりました。起動時に前の置き場へ戻すときも、その置き場のある画面で収めます
- ふきだしの縁は1ドット（`bubble.EDGE_WIDTH`）。Windows 11 が勝手に引く縁は消してあります（角を丸めた窓では段になって太く見えるため）。丸みは窓のリージョンと同じで、ペンで引くので角でも太りません
