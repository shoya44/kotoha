# ことは：将来拡張の候補

以下は未実装の検討候補であり、実装予定や受入基準ではありません。現行機能は [全体仕様](01_全体仕様.md) を参照してください。Webチャット・静止画像表示・記憶の保護と削除は既に実装されています。

必要性が生じた時に範囲と費用を決め、既存の会話・保存・記憶処理を維持できる小さな変更から検討します。

| 候補 | 検討する条件 |
|---|---|
| 感情による口調・想起の調整 | 会話表現の不足が具体的になった時。事実を感情で書き換えない |
| 学習候補の承認画面 | 記憶や手続きの自動更新を事前に確認したくなった時 |
| 記憶の統合・再要約 | 重複記憶の管理が難しくなった時 |
| 記憶の検索・訂正・保護解除UI | 現在の一覧・保護・削除だけでは管理が足りない時 |
| アバターの表情・動作 | 静止画像以上の表現が必要になった時 |
| 音声入出力 | 音声での会話が必要になった時 |
| PostgreSQL・常時稼働環境 | ローカルSQLiteとPC稼働時間では用途を満たせなくなった時 |
| 複数端末同期 | 同じWebサーバーへの接続以外に、端末ごとのデータ保持が必要になった時 |
| ローカルLLM | 外部送信を減らす必要があり、PC性能と会話品質が要件を満たせる時 |
| 用途別モデルの使い分け | 現在のGemini共通モデルでは品質・速度・費用の要件を満たせない時 |
| グラフ表示・埋め込み検索 | 記憶の確認やタグ検索に具体的な限界が出た時 |

導入するサービスやモデル、スキーマ変更、同期時の競合処理は、その候補に着手するときに決めます。
