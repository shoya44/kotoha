## LLM の使いどころ

言葉を作るのは Gemini、意味の近さを測るのは Ollama。**どちらも、無くても会話の骨組みは止まりません**（Gemini が落ちれば返事が無いだけ、Ollama が落ちればタグ命中だけになる）。

| いつ | 何を頼む | 出力の形 | 頻度の上限 |
|---|---|---|---|
| 会話1往復 | ことはとしての返事 | 本文 ＋ 内部タグ | 発言ごと |
| ことはから言うとき | 朝の一言・頼まれごと・見守り・声かけ・「そういえば」 | 本文 ＋ 内部タグ | 巡回ごとに1通にまとめる |
| 記憶整理（固着） | 未処理の会話 → 記憶の候補・再確認・訂正 | JSON | 会話が途切れたとき。失敗3回で諦める |
| 日記 | 前の日の会話 → 三〜五行 | 本文 | 1日1回（話さなかった日は呼ばない） |
| 夜の整理 | ここ1週間の記憶と日記 → 寄せる・直す・閉じる | JSON | 1日1回（材料2件未満なら呼ばない） |
| 習慣と信頼 | ここ2週間の日記 → 習慣と信頼 | JSON | 週に1回（日記7日ぶん以上） |
| 意味の座標（Ollama） | 記憶・日記・発言 → ベクトル | 数列 | 記憶と日記は裏の巡回で32件ずつ。発言は1往復に1回 |

### Gemini の入出力

| | |
|---|---|
| 送り先 | `{GEMINI_BASE_URL}/chat/completions`（OpenAI互換） |
| モデル | `gemini-3.5-flash-lite`（無料枠の範囲で使う想定） |
| 役割 | **すべて1件の user メッセージ**。固定ルールも人格も同じ1通に入れる |
| 上限 | `MAX_OUTPUT_TOKENS`、`TEMPERATURE`、`TIMEOUT_SECONDS`。整理・日記・振り返りは別の上限 |
| 再試行 | `LLM_ATTEMPTS` 回。ただし 429（枠切れ）は**投げ直さない**（失敗も枠を食うため） |
| 通話 | `stream: true` で受け取り、文の切れ目まで来たぶんから渡す |

### Ollama（bge-m3）の使い方

- 長さ1に揃えたベクトルを `memory_vectors` / `diary_vectors` に持ち、近さは内積ひとつ
- 発言の座標は**1往復に1回だけ**作り、記憶と日記の両方に使う。比べる相手が1つも無ければ作らない
- 止まっていれば `EMBED_RETRY_SECONDS` のあいだ諦め、巡回が試し続けて戻れば再開する。会話を待たせない

## 発言生成（会話1往復）

```
発言
 │
 ├─ 発言を保存（turn_id を採る）
 │    └─ 直前が「発言だけ・同じ文」なら、その往復を使い回す（送り直し）
 │
 ├─ Fast / Slow を決める（router）
 │    ├─ FAST_ENABLED=false → 必ず Slow
 │    ├─ 40字超 / 疑問詞 / 過去を指す語 / 記憶の操作語 → Slow
 │    ├─ 機械のことを頼む語 → Slow（Fast は [DO:] を読まないため）
 │    ├─ 記憶のタグに当たる → Slow
 │    └─ それ以外 → Fast
 │
 ├─ 記憶を集める（想起。Slow のみ意味検索まで）
 ├─ プロンプトを組み立てる
 ├─ Gemini へ送る（通話なら流しながら受け取る）
 │    └─ Fast の1行目が NEEDS_SEARCH → 同じ往復のうちに Slow でやり直す
 ├─ 返答からタグを外す
 ├─ 返答を保存・機嫌・話題・記憶の利用実績（強さ）・頼まれごと
 └─ 画面へ返す（＋ PC操作があれば最後に実行）
```

### プロンプトの組み立て

上から順に、空でないブロックだけを空行で継ぎます。

| # | ブロック | 中身 | Fast |
|---|---|---|---|
| 1 | 固定ルール | `prompts/fixed_rules.txt`。話し方の約束と内部タグの作法 | ○ |
| 2 | 人格 | `data/prompts/persona.txt` があればそれ、無ければ `prompts/persona.txt` | ○ |
| 3 | 時刻と状況 | 現在日時・曜日／今日の予定／前回の会話からの間隔／いまのことはの様子／機嫌とそのきっかけ・薄れ具合・気分の言葉／相手への信頼／さっきまでの話題／姿の居場所／返事のなかった声かけ／覚えている件数／相手の様子／Claude Code の様子 | 一部 |
| 4 | PCの中身 | 機械のことを聞かれたときだけ。CPU・メモリ・ディスクと、頼める操作の一覧 | × |
| 5 | 預かっている頼まれごと | これから言う予定のもの（`#番号` つき。取り消しに使う） | × |
| 6 | 日記（ここ数日） | 直近3日ぶん。だらしなさが続けば一言言ってよい | × |
| 7 | 思い当たる日記 | 発言に意味の近い日（最大2件。ここ数日ぶんは除く） | × |
| 8 | 相手の習慣 | 何となく覚えていること（最大6件） | × |
| 9 | 基本情報 | 保護記憶（ピン留め） | ○ |
| 10 | 気になっていること | 続きのある話（`open_topic`）を最大2件。「続きを聞いてもいい。毎回は聞かない」と添える | × |
| 11 | 関連記憶 | タグ命中・意味の近さ・最近のエピソード | × |
| 12 | 直近の会話 | 最大 `RECENT_TURNS × 2` 件。字数超過時は古いほうから落とす | ○ |
| 13 | 今回の発言 | ユーザーの発言（ことはから話すときは、代わりに「何を言うか」の指示） | ○ |
| 14 | Fastの補足 | 「記憶の検索が要るなら1行目に NEEDS_SEARCH」 | Fast のみ |

記憶の1行は `- [id:12][09-18][event] 歯医者に行った` の形です。**ラベルが本文と同じ量を占めていた**ので、層は種類から分かるぶん省き、年も今年なら省いています。

### 状況の行に入るもの

**声をかけたのに返事がなかったことは、ことはに渡します**（`chat.unanswered`）。直近の会話の中に、ことはから始まった往復があり、1時間以上返事が無ければ「返事のなかった声かけ: 1回（最後は3時間前）」の1行が入ります。水に流すか根に持つかは人格に任せますが、あったことは渡します。直近の会話だけを見るので、話しているうちに窓から出て薄れます。朝のひとこと（その日限り・`extractable=0`）は数えません。

**いまのことはの様子は日替わりです**（`figure.situation`）。時間帯ごとに数個の様子を人格の範囲で置き、絵と同じ式（日付と時間帯）で1つに決めます。同じ日・同じ時間帯なら何度聞いても同じで、さっき言ったことと食い違いません。

**続きのある話は、それと分かる形で渡します。** `open_topic` は想起で毎回2件まで確保し（`retrieve.OPEN_TOPIC_LIMIT`）、プロンプトでは「気になっていること」として関連記憶から分けます。混ぜると、モデルには済んだ話と区別がつかず、人格にある「そういえばあれ、どうなった？」が出ません。

**自分の様子は、起きたときと設定を変えられたときに書き、1日だけ渡します**（`talk/myself.py`）。巡回が毎分「生きている印」を書いていて、起きたとき（lifespan の `myself.wake`）にその差が止まっていた長さになります。同時に `kotoha/` 配下の py のハッシュと、見張っている設定のオン／オフを前回の印と見比べます。30分未満の止まりは言いません（トレイの上げ直しは、うたた寝）。「自分の様子（3時間前）: 3時間ほど止まっていて、起き直した」のような1行になり、24時間で消えます。鳴らしません。触れるかどうかは固定ルールで「触れてもいいし、触れなくてもいい」にしてあり、感じたことは `[MOOD:]` で申告されます。機嫌の書き手は増やしません。

**Claude Code の様子は、記録の末尾だけを読んで渡します**（`talk/coding.py`）。`~/.claude/projects/<場所>/<id>.jsonl` の最後の数行から、種類と時刻だけを見ます。何を頼まれて何を書いたかは読みません。30分動きが無ければ「止まっているように見える」と言います。

### 気分の調整

機嫌は申告制です（`[MOOD:]` が来たときだけ変わる）。**きっかけも一緒に申告させます**（`chat.mood_reason`）。理由の無い機嫌は3〜4ターンに1回ころころ変わっていました（実測 36回/126ターン）。「今の機嫌: すねている。きっかけ: 返事がなかったから」と戻せば、次の往復も同じ機嫌でいられるし、相手が謝ったら直る道もできます。

```
申告 [MOOD: すねている|返事がなかったから]
 │
 ├─ ラベルと、きっかけを app_state に（mood / mood_why / mood_at）
 │
 ├─ 黙っているあいだ、半減期（既定1時間）で薄れる ─ chat.mood_intensity
 │     濃さ ≥0.7 まだ強い ／ ≥0.35「薄れてきた」／ ≥0.15「だいぶ薄れた」／ それ未満 → 時間帯の下地
 │     話しているあいだは時刻が進むので薄れない
 │
 ├─ 中身は2軸 ─ chat.mood_axes（快−不快、元気−疲れ。-1〜1）
 │     ラベルの座標（MOOD_AXES）から、時間帯の下地の座標へ、濃さぶんだけ寄る
 │     言葉にして添える ─ mood_words「気分は少し沈み気味、元気は低め」
 │
 └─ 時間帯に合わないラベルは引きずらない ─ figure.keeps
       深夜の「眠い」は朝になれば外れる。区切りの表は figure.py が1つだけ持つ
```

申告が無ければ、その時間帯ぶんで埋めます（`figure.MOOD_PRIOR`）。声にも同じ機嫌が乗ります（`serve/voice.py` の `MOOD_VOICE`）。

**相手への信頼**も1行渡します（`habits.trust_line`。「相手への信頼: 高い（頼まれごとを守っている）」）。週の振り返りで高い / ふつう / 低め を一段ずつ動かし、叱るかどうかはこれを見て決めます（高いなら「珍しいね」で済ませ、低めならちゃんと言う）。

**さっきまでの話題**も1行持ちます（`[TOPIC: 引っ越しの話]` → `app_state.topic`）。往復ごとにプロンプトを組み直しても話題は続き、直近12往復の窓が切れても「さっきまでの話題: 引っ越しの話（10時間前から）」として渡るので、翌日の「昨日の続きだけど」まで届きます。変わったときだけ書かせ、来なければ前のまま。`[TOPIC: なし]` で終わり、`TOPIC_KEEP_HOURS`（既定24時間）で忘れます。

### 返答の加工

返ってきた文から、**必ずこの順**で外します。

1. `[USED: 1,2]` → 使った記憶のid（数字だけ拾う。Fast では保護記憶のIDだけ通す）。**使った記憶は強さが足される**
2. `[MOOD: すねている|返事がなかったから]` → 機嫌と、そのきっかけ（知らないラベルは捨て、前の機嫌を保つ。きっかけは40字まで）
3. `[TOPIC: 引っ越しの話]` → さっきまでの話題（30字まで。「なし」は終わりの印）
4. `[FACE: 笑う]` → 返事の顔（知らないラベルは捨てる。話した直後の30秒だけ絵に効く。[12 姿の決まり方](12_姿の決まり方.md)）
5. `[DO: 名前]` → PC操作（表にない名前は捨てる。**Slow のみ**）
6. `[REMIND: 2026-09-18 09:00|歯医者|毎日]` → 頼まれごと（読めない時刻は黙って捨てる。3つ目は繰り返し）
7. `[DROP: 3]` → 頼まれごとの取り消し（本人に頼まれたぶんだけ）
8. `strip_tags` で**ひと拭き** ── 崩れたタグが本文に残ると、そのまま画面に出るため

残った本文が返事です。保存するのも、この本文です（履歴にタグを残しません）。

### 流しながら喋る（通話）

```
Gemini ──（届いたそばから）──> 文の切れ目まで来たぶん ──> 1行1件のJSON ──> 画面
                                                              └─ 届いた順に読み上げの行列へ
最後に {"done": 返事・機嫌・預かり・取り消し・last_id}
```

- **タグの途中では切りません。** 揃ったタグは外し、開きっぱなしの `[` から先は手元に置きます
- **Fast では使いません。** 1行目が `NEEDS_SEARCH` のことがあり、喋ってしまってからでは取り消せないため
- 途中で切れても、**言いかけたぶんは捨てません**。1文字も来ていないときだけ、投げ直しのある普通の道へ落ちます
- 生成は1本のスレッドの中だけで回します（**SQLiteの接続は、作ったスレッドでしか触れない**ため）

## 記憶処理

人の記憶と同じ3段で組んであります。**固着**（会話を記憶に変える）、**想起**（発言に合わせて引く）、**忘却**（触れられないものが薄れて消える）。それに日記と習慣（[02 機能](02_機能.md)）が乗ります。

### 固着（記憶整理）

```
未処理の往復（最大20往復・20,000字）← 会話が途切れてから（IDLE_SECONDS）
 │
 ├─ 既にある近い記憶を添える（タグ命中・意味の近さ）
 ├─ Gemini へ「JSONで返せ」と頼む
 ├─ 検証 ── 層と種類の組み合わせ、字数（episode 400 / semantic 200）、日付、タグ
 ├─ 保存 ── source_key で重複しない。言い直しだけの候補（近さ ≥ EMBED_MERGE_FLOOR）は作らず既存を確かめ直す
 │         新しい記憶は強さ1。再確認・訂正は強さが足される
 └─ 処理済みの位置を進める
```

失敗が3回続いたら、そのバッチは諦めます（**言えるまで毎分試すと、そのたびに枠を1回ずつ食う**ため）。

### 固着の2段目（夜の整理）

```
日記を書いたあと、1日1回 ← review.due
 │
 ├─ 材料: ここ1週間に確かめた記憶（ピン留めは除く）＋ 続きのある話すべて ＋ ここ1週間の日記
 │        2件未満なら Gemini を呼ばない
 ├─ Gemini へ「JSONで返せ」と頼む
 ├─ 寄せる ── 同じことを言う記憶を1つに。出どころ・タグ・繋がりは残す方へ、強さも足す
 ├─ 直す   ── 日記と食い違う記憶を書き直す。座標は捨てて作り直し
 └─ 閉じる ── 済んだ話題（open_topic）を事実（fact）に
```

各4件まで。作りはしません。失敗した日はその日はもう試しません。

### 想起

```
発言 ＋ 直近会話
 │
 ├─ 保護記憶（pinned）           → 「基本情報」へ（上限 PINNED_LIMIT）
 │
 ├─ タグ命中                     ┐
 │   記憶のタグが文に含まれるか   │  **強い記憶が先**。同じ強さなら
 │   よく使われたタグ順に候補     │  よく使われたタグ順
 │                               ├→ 候補をまとめ、関連（memory_edges）を1hopたどる
 ├─ 意味の近さ（Ollama）         │   → 「関連記憶」へ（上限 RELATED_LIMIT）
 │   類似度 × 強さの重み ≥ EMBED_FLOOR │  うち EMBED_RESERVE 件は意味枠として確保
 │   床のすぐ下（−AFTERTHOUGHT_MARGIN）は1件だけ預かる → 「そういえば」
 │                               │
 └─ 最近のエピソード             ┘

 発言の座標（1往復に1回だけ作る）
 └─ 日記の近さ                    → 「思い当たる日記」へ（上限 DIARY_RECALL_LIMIT。ここ数日ぶんは除く）
```

`EMBED_FLOOR` の 0.62 は、実際に当たった組の類似度の中央値から置いています。Ollama が止まっていればタグ命中だけで動きます。強さの重みは `min(1, 0.7 + 0.3 × 強さ)`。新しい記憶（強さ1）で1、薄れるほど軽くなるので、薄れた記憶は強い手がかりが要ります。

### 忘却（強さ）

```
記憶の強さ（strength, strength_at）
 │
 ├─ 日ごとに半分ずつ薄れる。半減期は「新しい記憶が触れられずに消えるまで」（EPISODE_DAYS 30 / SEMANTIC_DAYS 180）から導く
 ├─ 思い出すと足される（[USED:]、再確認、訂正、画面で直したとき、寄せたとき）
 │     足すぶん = GAIN × (1 + log(1 + 前回使ってからの日数))   ← 間が空いてから思い出すほど大きい
 │     上限 STRENGTH_MAX
 ├─ 消える時刻 = 強さが床（STRENGTH_FLOOR）を切る時刻 → expires_at に書く
 │
 └─ 24時間ごと（MAINTENANCE_SECONDS）: 控えを取ってから、期限切れ・ピン留めでないものを消す
      使われないタグの数えも戻す（TAG_RESET_DAYS）
```

ピン留め（`pinned=1`）と、`expires_at` が NULL の記憶（CUI の `note`）は消えません。

### 日記・習慣・信頼

```
日付が変わって（DIARY_HOUR 以降の最初の巡回）
 └─ 前の日の会話 ＋ 言った頼まれごと → ことはが三〜五行 → diary（1日1件。話さなかった日は定型・API なし）
      寝ていた日は1回の巡回に1日ずつ（最大7日）

日記が7日ぶん溜まったら、週に1回
 └─ ここ2週間の日記 ＋ いまの習慣 ＋ いまの信頼 → 習慣（最大6件。挙がらなければ退く）＋ 信頼（一段ずつ）
```

## 裏の巡回（60秒ごと）

3つを順に回します。どれかが落ちても残りは続け、**落ちたことは必ず書き残します**。

```
① 巡回（会話と同じ順番待ちに並ぶ）
   ├─ 朝の材料を先に取る ← ロックの外（天気・地震は各8秒待つため）
   ├─ 生きている印を書く（止まれば、次に起きたとき長さが分かる）
   ├─ 前面アプリを1つ数える
   ├─ 記憶整理（固着） ← 未処理があり、かつ会話が途切れているとき
   ├─ 控えを取る      ← 前回から24時間
   ├─ 忘却            ← 控えのあと（順番に意味がある）
   ├─ 日記            ← 日付が変わっていて、前の日がまだなら
   ├─ 夜の整理        ← 日記のあと、1日1回
   ├─ 習慣と信頼      ← 週に1回
   ├─ 言うことを集める（このあいだは鳴らさず預かる）
   │    頼まれごと → 朝のひとこと → 見守り → Claude Code → 暇なときの声かけ → そういえば
   ├─ 預かったぶんをまとめて1通で言う
   └─ 姿を送り直す
② ベクトル（Ollama往復。並ばせない＝会話を止めないため）
   └─ 座標の無い記憶と日記を32件ずつ。新しい記憶は近い記憶と結ぶ（memory_edges）
③ 見張り（音声エンジン・Ollama・ディスク。確かめるあいだは並ばない）
```

**時計が回り始めるのは `serve/web.py` の lifespan だけ**です。取り込んだだけでは始まりません。

## ツール（手続き）

言葉を作るのではなく、決まった手順で動くもの。**言う段になったら、みな同じ道（announce）を通ります。**

### 頼まれごと（リマインド）

```
会話で頼まれる → 返事の [REMIND: 時刻|用件|繰り返し] → reminders（chain=0）
 │
 ├─ 毎分: 時刻が来たものを言う（通知の間を待たない）。12時間より古いものは畳む
 │    ├─ 繰り返しなら、次に当たる日のぶんを入れ直す（毎日 / 平日 / 休日 / 曜日の組）
 │    └─ 言う回だけ、ことはが自分に [REMIND:] を書ける → 追いかけ（chain+1。上限6）
 ├─ 返事があった（会話・「あとで」）→ 追いかけは全部消える
 ├─ 「あとで」→ 30分後に入れ直す
 └─ 取り消し → 画面から、または会話の [DROP: 番号]（本人に頼まれたぶんだけ）
```

### 朝のひとこと

```
BRIEFING_HOUR になった最初の巡回（GRACE_HOURS まで遅れてよい。それ以上なら黙る）
 └─ 空模様（Open-Meteo）＋ ゴミの日 ＋ 今日の予定 ＋ 頼まれごと ＋ 昨日の日記 ＋ 夜の地震 ＋ 暦の期限切れ
     → 1通にまとめて言う（その日限り。長期記憶には溜めない）
```

### 見守りと声かけ

| 手続き | 条件 | 1回の上限 |
|---|---|---|
| 根の詰めすぎ | 同じアプリを `LOOKOUT_SIT_HOURS` 続けて前面に | 声をかけたら数え直し |
| 夜更かし | `LOOKOUT_LATE_HOUR`〜`MORNING_HOUR` に起きている | その晩に1回 |
| Claude Code | 頼んでいた作業が終わって返事待ち（5分未満は言わない） | 作業ごと |
| 暇なときの声かけ | 会話が `REACH_OUT_AFTER_HOURS` 途切れ、時間帯の中 | `REACH_OUT_INTERVAL_HOURS` に1回 |
| そういえば | 預かった記憶があり、会話が `AFTERTHOUGHT_AFTER_MINUTES` 途切れ、時間帯の中 | 1日1回 |
| 見張り | AivisSpeech / Ollama が落ちた瞬間、ディスクの空きが `DISK_WARN_GB` を切った瞬間 | 状態が変わったときだけ |

### ことはから言うときの道（announce）

```
何か言いたい（朝・頼まれごと・見守り・声かけ・そういえば）
 │
 ├─ 口を開ける状態か（通知が使える or 姿が出ている）
 ├─ 間が空いていない or 巡回の最中 → 預かる（DBに置くので落ちても消えない）
 │    頼まれごとだけは間を待たない（7時に起こしてを7時10分に言っても仕方がない）
 │
 └─ 言う
     ├─ 言葉を作る（Gemini）。作れなければ定型（plain）で言う。定型の無いもの（追いかけ・そういえば）は黙る
     ├─ 履歴に残す
     └─ 届ける ── 姿が見えていればふきだし／でなければ通知
          └─ 届かなかったら、作り直さず配り直す（次の巡回で）
```
