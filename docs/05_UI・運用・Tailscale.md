# ことは：UI・運用・Tailscale

運用設定の数値は既定値です。変更は `settings.bat` から `.env` で行います。設定一覧は [README](../README.md#設定の変更) を参照してください。

具体的なセットアップとコマンド一覧は [README](../README.md) を参照してください。

## ダブルクリックでの起動

`start.bat` は依存関係・設定の確認、DB初期化、Webサーバー起動、Tailscale ServeのHTTPS配信、ブラウザー表示を行います。起動済みのサーバーはアプリ識別とトークンを確認して再利用します。ブラウザーはTailscale側URLでの応答を確認してから開きます。

`tools.bat` は起動、CUI、状態・記憶確認、バックアップ、Tailscale、README、設定編集、セットアップの操作メニューです。8番は `settings.bat` を呼び出し、`.env` の不足項目追加・編集・保存後の検査を行います。`setup.bat` は仮想環境・CUI/Web用依存関係・DBを準備します。

Tailscaleのインストール・ログインは事前に必要です。配信できない場合は理由を表示し、ブラウザーは開きません。停止はサーバーのウィンドウでCtrl+Cを押します。通常のアクセスログは非表示で、KOTOHA_DEBUG=trueのときに表示します。警告・エラーは常に表示します。

## CUI

プロジェクト直下で `.\kotoha.bat start` を実行します。起動時はDBを初期化し、条件を満たせば整理してから直近会話の末尾最大6メッセージを表示します。最後の発言がユーザー入力だけなら未完了ターンの案内を表示します。

| 入力 | 動作 |
|---|---|
| 通常の文章 | 会話生成 |
| `/status` | DBパス、モデル、メッセージ数、前回会話・最終整理・最終忘却の時刻 |
| `/memory` | 意味記憶の一覧 |
| `/memory episodes` / `semantics` | 指定種類の一覧、最大30件 |
| `/memory pinned` | 保護記憶、最大50件 |
| `/memory tags` | タグ、最大100件 |
| `/memory show <id>` | 本文・日時・期限・保護・タグ・接続・出典ID |
| `/consolidate` | 記憶整理 |
| `/protect <id>` | 自動削除から保護 |
| `/forget <id>` | 保護状態を問わず即時削除。確認画面なし |
| `/exit` | メンテナンス後に終了 |

Ctrl+Cまたは入力の終端でも終了します。保護解除、手動訂正、タグ検索の管理コマンドはありません。

## Webチャット

`KOTOHA_WEB_TOKEN` を設定してから `.\kotoha.bat web` を起動します。起動時にDBを初期化するので事前の `init` は不要です。既定の接続先は `http://127.0.0.1:8000` です。

画面には認証入力、会話履歴、入力欄、送信ボタン、通話ボタン、応答待ち表示、時刻、処理モード、立ち絵、設定シートがあります。Enterで送信、Shift+Enterで改行します。返答は生成完了後に表示し、ストリーミングは行いません。管理用スラッシュコマンドはWebでは通常の文章として扱います。

立ち絵は時間帯で切り替わり、ときどきまばたきします。設定シートでは時刻表示と読み上げの切り替え、トークンの変更ができます。画面のファイルは `index.html` / `style.css` / `app.js` に分かれています。

| HTTP | パス | 内容 |
|---|---|---|
| GET | `/` | チャットHTML |
| GET | `/static/...` | 静的ファイル |
| GET | `/api/history?limit=40` | 会話履歴。既定40メッセージ |
| POST | `/api/chat` | `{"text":"発言"}` を受け取りreplyとmodeを返す |
| POST | `/api/speak` | `{"text":"読み上げる文"}` を受け取りwavを返す |

上記3つのAPIは `X-Kotoha-Token` ヘッダーを検証します。画面・静的ファイルはトークン検証の対象外です。ブラウザーは認証成功時にトークンをlocalStorageへ保存します。WebはCtrl+Cで停止します。

## 読み上げと通話

`/api/speak` はVOICEVOX互換エンジン（AivisSpeechなど）へ本文を渡し、返ってきたwavをそのまま画面へ返します。既定の接続先は `http://127.0.0.1:10101`、既定の話者IDはコハクのノーマルです。読み上げは合計300文字で切ります。

本文は句点や改行で分け、1つ目を鳴らしながら次を合成します。合成にかかる時間は「0.7秒＋文字数×0.04秒」ほどなので、全文を一度に渡すより最初の声が早く出ます。10文字に満たない断片は前につないで、細切れの合成で間延びしないようにしています。エンジンが止まっている、`KOTOHA_VOICE_ENABLED=false`、本文が空のいずれでも503または400を返すだけで、会話は続きます。

通話は画面側の機能です。ブラウザのWeb Speech APIで聞き取ったテキストを通常の `/api/chat` へ送り、返答を読み上げ、読み上げが終わるとまた聞き取りに戻ります。読み上げ中はマイクを開かないため、スピーカー利用でも自分の声を拾いません。割り込みはできません。

返答が0.7秒で返らないときは、先に「えっと」などの短い間つなぎを鳴らします。音声は通話の開始時にまとめて作って使い回すので、鳴らすまでの待ちはありません。鳴らし終えてから本文に移るため声は重なりません。すぐ返せたときは鳴らさず、同じ言葉が続けて出ないようにしています。音声エンジンが応じないときは間つなぎなしで動きます。

音声入力はChrome / Edgeが必要で、認識のためブラウザが音声をGoogleへ送信します。マイクの利用にHTTPSが必要なので、`localhost` 以外ではTailscale経由のURLを使います。対応しないブラウザでは通話ボタンを表示しません。

## Tailscale経由の利用

PCとiPhoneを同じTailscaleネットワークに接続します。アプリは127.0.0.1で待ち受け、Tailscale ServeがHTTPSで中継します。配信先URLはTailscaleの状態から取得します。別アプリやFunnelが同じ配信ポートを使用している場合は上書きせず、別ポートの指定を案内します。

Serveはバックグラウンド設定として保持します。停止・設定解除の手順と設定項目は [README](../README.md#iphone・リモート利用) を参照してください。PCの停止・スリープ中は利用できません。

## バックアップと復元

保存先はDBと同じフォルダーの `backups/`、保持は最新7件です。前回から24時間が経っていれば、Webのバックグラウンド確認とCUIの終了時に自動で作成します。忘却より先に取るため、期限切れで消えた記憶も直前のバックアップには残ります。`.\kotoha.bat backup` でいつでも手動作成でき、手動実行は自動の間隔に影響しません。

復元はCUI・Webを停止し、現在のDBを退避してからバックアップをDBの配置先に戻します。プロンプトと設定はDBバックアップには含まれません。復元後はstatusと記憶一覧で内容を確認します。

## 運用上の範囲

- 会話と記憶はSQLiteに保存し、応答・整理に必要な内容をGemini APIへ送ります。
- 明示削除はノードと関連リンクを削除します。原文、他のノード、バックアップ、API側の保持データは消しません。
- WebとCUIの同時起動をまたぐ会話の排他制御はありません。
- Webバックグラウンド整理の失敗は現在画面に表示されません。
- 読み上げ・通話はWebのみの機能です。CUIでは利用できません。
- `tests/` はいずれも一時DBだけを使う自動テストです。実DBには書き込みません。
