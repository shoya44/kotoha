# 12 姿の決まり方

いまどの絵を出すかの表。**決めるのは脳（`talk/figure.py`）だけ**で、器（トレイ・会話画面）は受け取った名前を描き、暇なときの所作を選ぶだけ。器の動きは [11 動き](11_動き.md)、絵の作り方は [08 立ち絵の作り方](08_立ち絵の作り方.md)。

## 決める材料

| 材料 | どこから | いつ変わる |
|---|---|---|
| 時刻・日付 | 時計 | 常に |
| 機嫌（ラベル） | 返事の `[MOOD:]`。黙っていると半減期で薄れ、濃さ 0.15 を切ると時間帯の下地に戻る（`chat.current_mood`） | 返事のたび |
| 返事の顔 | 返事の `[FACE:]`。**話した直後（30秒）だけ**効く（`chat.current_face`） | 返事のたび |
| 同じアプリを続けている時間 | 前面アプリの見張り（`presence.streak`） | 巡回 |

見直すのは、会話のあと・自分から話したあと・巡回（60秒おき）・器が繋がったとき（`hub.refresh`）。

## ① 振る舞い（上から順に、最初に当てはまったもの）

| 優先 | 振る舞い | 条件 | 絵 |
|---|---|---|---|
| 1 | talk | 話した直後（30秒以内。巡回が60秒おきなので、見た目は30〜90秒） | 返事の顔（②）。顔が無ければ `talk` |
| 2 | sleep | 2〜6時、または機嫌が「眠い」（「眠い」は21〜2時だけ持ち越す） | `sleep` |
| 3 | worry | 同じアプリを `LOOKOUT_SIT_HOURS`（既定3時間）以上 | `worry` |
| 4 | sulk | 機嫌が「すねている」 | `sulk` |
| 5 | happy | 機嫌が「機嫌がいい」 | `happy`（器が2回跳ねる） |
| 6 | idle | 上のどれでもない（「ふつう」「疲れ気味」） | 時間帯の絵（③） |

## ② 返事の顔（`figure.FACES`）

返事ごとに LLM が付ける一瞬の顔。機嫌（長く続く）とは別。ふだんの顔なら付かない。

| `[FACE:]` | 絵 |
|---|---|
| 笑う | `laugh` |
| 嬉しい | `happy` |
| 照れる | `fidget_shy` |
| 考える | `think` |
| 困る | `worry` |
| むっとする | `sulk` |
| 驚く | `talk`（**絵がまだ無い**） |

ラベルを変えるときは `prompts/fixed_rules.txt` の一覧も揃える（`tests/test_figure.py` が見張っている）。絵を足したら右の列を書き換えるだけ。

## ③ 時間帯の絵（`figure.GROUPS`。その日のあいだは変わらない）

様子（言葉）と絵は同じ式で選ぶので、**同じ数・同じ順**に並べる（`tests/test_figure.py` が見張っている）。

| 時間帯 | 様子 → 絵 |
|---|---|
| 朝 6–11 | ぼーっと → `daydream` ／ コーヒー → `coffee` ／ 布団でスマホ → `phone` ／ 何もしていない → `wave` |
| 昼 11–14 | ダラダラ → `laptop` ／ 洗い物を先延ばし → `dishes` ／ 昼ごはん未定 → `think` ／ ノートPC開いたまま → `laptop` |
| 午後 14–17 | 昼寝やおやつ → `snack` ／ プリンで迷う → `snack` ／ 昼寝あけ → `nap` ／ 床で天井 → `floor` |
| 夕方 17–21 | 風呂・夕食のあと → `book` ／ お風呂まだ → `bored` ／ 洗濯物の山 → `phone` ／ 甘いもの → `snack` |
| 夜 21–2 | ゲームかスマホ → `cards` ／ 寝るつもりでスマホ → `phone` ／ ゲームがやめられない → `laugh` ／ 明日こそ早起き → `write` |
| 深夜 2–6 | 寝ている → `sleep` |

## ④ 所作の出しどころ（`figure.FIDGET_FIT`）

所作（`fidget_*`）を出すかどうかと間は器が決める（振る舞いが idle か happy のとき、30〜90秒おき）。脳は**いまは合わないもの**を `fidgets_off` として渡し、器はそれを除いて選ぶ。**表に無い所作はいつ出してもよい。**

| 所作 | 出してよいとき |
|---|---|
| `fidget_yawn` | 朝・午後・夜 |
| `fidget_stretch` | 朝・午後 |
| `fidget_pillow` | 午後・夜 |
| `fidget_hungry` | 昼・夕方 |
| `fidget_cold` | 11〜3月 |
| `fidget_fan` | 6〜9月 |
| `fidget_spin` `fidget_giggle` `fidget_hum` `fidget_kick` | 機嫌が「ふつう」「機嫌がいい」（疲れているときは出さない） |

## まだ足りないもの

| | いま | 欲しい絵 |
|---|---|---|
| 驚く | `talk` のまま | 驚いた顔 |
| 眠い（夜） | 布団で寝ている `sleep` | 起きているがうとうとしている絵 |
| 疲れ気味 | 時間帯の絵のまま（`tired` は不採用） | ── |
| 振る舞いの絵 | `happy` `sulk` などは時間帯に関係なく1枚 | ── |

## 決めごと

- **判断は脳だけ。** 器に「この時間ならこの絵」を持たせない。器が増えても食い違わない
- **脳は動きの指示を出さない**（[11](11_動き.md)）。所作は「合わないもの」を渡すだけで、いつ出すかは器の癖
- 仕組みは表で持つ。条件を足すときは表に1行足し、関数の分岐は増やさない
