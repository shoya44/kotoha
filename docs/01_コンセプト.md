# 01 コンセプト

## ことはとは

**PCの中で暮らしている話し相手**です。持ち主ひとりのために動き、同じPCの中に記憶を持ち、時々そちらから話しかけてきます。

作るうえでの軸は3つだけです。

| | |
|---|---|
| **人間らしく在る** | 道具ではなく、居る人として。完璧に答えるより、知らないことを知らないと言えるほうが大事 |
| **単純に、軽く** | 依存は3つ（httpx / fastapi / uvicorn）。増やす前に、書けないか考える |
| **追える形にする** | なぜそうしたかが、あとから読める。測ってから決める |

## 全体像

```
                         家（持ち主のPC）
 ┌──────────────────────────────────────────────────────────────────┐
 │                                                                  │
 │   脳（uvicorn ── serve.web:app。プロセスひとつ）                      │
 │   ┌────────────────────────────────────────────────┐             │
 │   │ 会話  talk/chat.py   … プロンプトを組み、返事を加工  │             │
 │   │ 記憶  memory/        … 固着・想起・忘却・日記・習慣  │  SQLite      │
 │   │ 巡回  serve/jobs.py  … 60秒ごとの裏の仕事          │  data/       │
 │   │ 発言  serve/announce … 自分から言う。通知にまとめる  │  kotoha.sqlite3
 │   │ 器の取次 serve/hub.py … 実体の居場所を決める        │             │
 │   └───────┬───────────────────┬──────────────┬─────┘             │
 │           │ SSE / HTTP        │              │                   │
 │   ┌───────┴──────┐   ┌────────┴──────┐  ┌────┴─────────┐          │
 │   │ 会話画面      │   │ デスクトップの姿 │  │ タスクトレイ   │          │
 │   │ （ブラウザ/PWA）│   │ （mascot.pyw） │  │ （tray.pyw）  │          │
 │   └──────────────┘   └───────────────┘  │ 起動・見張り   │          │
 │        器                  器            └──────────────┘          │
 │                                                                  │
 │   家の中の道具: AivisSpeech（声）  Ollama bge-m3（意味の座標）           │
 └──────────┬───────────────────────────────────────┬───────────────┘
            │ Tailscale（外から同じ画面へ）               │
   ┌────────┴────────┐                        ┌──────┴──────────────────┐
   │ iPhone（PWA）    │                        │ 外のサービス               │
   │ 会話・通知の受け取り │                        │ Gemini（言葉を作る）        │
   └─────────────────┘                        │ OneSignal（通知）          │
                                              │ Open-Meteo / P2P地震情報   │
                                              └─────────────────────────┘
```

- **脳はひとつ。** 考える・決める・覚えるは、uvicorn のプロセスだけがやります。
- **器は複数。** 会話画面、デスクトップの姿、iPhone の PWA。どれも脳から来たものを見せ、人の言葉を脳へ渡すだけです。
- **記憶は SQLite 1ファイル。** 会話・記憶・日記・習慣・頼まれごと・覚えごとが全部ここにあります（[06 データベース](06_データベース.md)）。
- **外に出るのは言葉だけ。** 記憶とプロンプトの中身が出るのは Gemini だけです（通知に本文を載せる設定なら OneSignal にも）。

処理の流れは [03 処理フロー](03_処理フロー.md)、部位ごとの対応は [09 解剖図](09_解剖図.md) にあります。

## 語彙

同じ言葉を、コードと文書で同じ意味に使います。

| 言葉 | 意味 |
|---|---|
| **脳** | ことは本体。考える・決める・覚える。PCの中に**ひとつだけ** |
| **器**（うつわ） | 脳と人のあいだを取り次ぐもの。会話画面、デスクトップの姿、iPhoneのPWA |
| **実体** | いま姿を出している器。**一度にひとつだけ** |
| **家** | ことはが住んでいるPC |
| **往復**（turn） | 発言と返事のひと組。DBの `turn_id` |
| **預かり** | すぐ言えないとき、脳がためておく発言 |
| **固着** | 会話を長期記憶に変えること（記憶整理）。人の海馬がやること |
| **想起** | 発言に合わせて記憶を引くこと |
| **強さ** | 記憶が薄れる速さと出やすさを決める1つの数 |

## どのように「人間らしさ」を作っているか

人間らしさは、返事の文面だけでは出ません。**時間がたつと変わるもの**を持ち、**その場で言わないこと**を選び、**あとから思い出す**ことで出ます。ことはが持っている仕組みを、人のふるまいに対応させると次のとおりです。

| 人のふるまい | ことはの仕組み | どこに |
|---|---|---|
| 全部は覚えていない。使う記憶ほど残る | 記憶に**強さ**があり、日ごとに半減し、思い出すと足される。床を切ると消える | `memory/strength.py` |
| 思い出せそうで出ない | 薄れた記憶は、強い手がかりが無いと出ない（近さ × 強さの重み） | `memory/retrieve.py` |
| 風呂で「そういえば」と思い出す | 床のすぐ下だった記憶を1つ預かり、会話が途切れてから言う（1日1回） | `serve/jobs.py` `maybe_afterthought` |
| 寝ているあいだに整理される | 会話が途切れた空き時間に固着し、日記のあとに記憶どうしを寄せる・直す・閉じる | `memory/consolidate.py` `memory/review.py` |
| 一日の終わりに振り返る | 日付が変わったら、その日を三〜五行の日記に。話さなかった日も1件 | `memory/diary.py` |
| 何となく習慣を知っている | 週に一度、日記から習慣を最大6件に固め、挙がらなければ薄れる | `memory/habits.py` |
| 相手を信頼するかどうか | 同じ振り返りで、高い / ふつう / 低め を一段ずつ。叱るかどうかの根拠 | `memory/habits.py` |
| 機嫌は続き、そのうち戻る | 申告した機嫌が半減期で時間帯の下地へ戻る。中身は快−不快と元気−疲れの2軸 | `talk/chat.py` |
| 話題が続く | さっきまでの話題を1行持ち、翌日の「昨日の続きだけど」まで届く | `talk/chat.py` `[TOPIC:]` |
| 頼まれたことは覚えている | 時刻が来たら言い、返事が無ければ自分でもう一度言う時刻を決める | `memory/remind.py` |
| 相手を見ている | PCが動いているか、何を触っているか。席に居るのに「起きてる？」とは聞かない | `talk/presence.py` |
| 自分の様子が分かる | どれだけ止まっていたか、起き直したら中身が違うか、設定を変えられたか。何が変わったかは分からない。触れるかどうかは自分で決める | `talk/myself.py` |
| 時間帯で様子が違う | 朝はぼーっと、深夜は眠い。絵と言葉が同じ表から出る | `talk/figure.py` |
| 自分から声をかける | 朝の一言、頼まれごと、見守り、暇なときの一声。**言わずに鳴らさない** | `serve/announce.py` |
| 知らないことは知らないと言う | 固定ルールで縛る。身体経験や覚えていない過去を、あるように言わない | `prompts/fixed_rules.txt` |

どれも「言い方」は決めていません。**事実と状態を渡し、どう言うかは人格に任せます**。渡さなければ何も無かった顔で話すしかなく、渡しすぎれば型にはまります。その境目を、この表の1行ずつで決めています。

## 原則

### 人間らしく在る

- **していないこと・知らないことを、あるように言わない。** 身体経験、相手の気持ち、覚えていない過去、自分の仕組み。分からなければ、分かるふりをせずに聞き返す。
- **その日の事実を渡し、言い方は任せる。** 「今日は仕事（18:00まで）」のような事実だけを渡し、「いってらっしゃいと言え」とは指示しない。型にはめると人格が死ぬ。
- **黙って失敗しない。** 言えなかった・届かなかった・畳んだことは、必ずどこかに残す。持ち主が気づけない失敗がいちばん困る。
- **触れられない記憶は薄れて消える。** 忘れることも人間らしさのうち。ただし、消える前に控えを取る。

### 脳と器

**ことはの本体は、PCの中で動く脳ひとつです。** 記憶も機嫌も判断も、すべてそこにあります。

| | |
|---|---|
| 脳がやること | 考える。決める。覚える。どこに出るかを選ぶ |
| 器がやること | 脳から来たものを見せる・聞かせる。人の言葉を脳へ渡す |
| 器がやらないこと | 考えること。決めること。会話の状態を持つこと |

姿が出るのは一度にひとつの器だけで、**どこに出るかは脳が決めます**（器が取り合うのではない）。これで「脳はひとつ、器は複数」が、人の「身体はひとつ」と食い違わずに済みます。

> ⚠️ **取り込んだだけでは、何も始めません。** モジュールを import した時点でスレッドを回したり接続を開いたりしないこと。かつてトレイが定数ひとつのために脳を取り込んでいたせいで、脳が2つのプロセスで回りました（[history/02](history/02_事故と対処.md)）。仕事を始めるのは、脳として動き出すとき（`serve/web.py` の lifespan）です。

### 単純に、軽く

- 依存は **httpx / fastapi / uvicorn** の3つ。トレイもデスクトップの姿も PNG の読み書きも、`ctypes` と標準ライブラリで書いてあります。
- 外のサービスは、鍵の要らないものを選びます（天気・地震）。要るものは Gemini と OneSignal と、家の中の AivisSpeech / Ollama だけです。
- **ひとつのことは、ひとつの場所に。** 時間帯の区切りは `talk/figure.py`、通知を鳴らすのは `serve/announce.py`、`app_state` のキーは `memory/db.py`、時計は `clock.py`。2か所に書いた瞬間から、片方が古くなります。
- **人に近づけるときも、列や口を増やさない。** 記憶の強さは列2本、話題と信頼は覚えごと2つずつ、気分の2軸は表1つ。日記の座標は記憶と同じ道。

### 追える形にする

- **測ってから決める。** 「速くなりそう」で入れない。記憶整理をローカルLLMへ移す案は、想起一致 0.00〜0.03 という実測で却下しました（[history/01](history/01_検討と見送り.md)）。数値の仮置きは [10 気になる点と見直し手順](10_気になる点と見直し手順.md) に集めてあり、測ってから動かします。
- **決めたことは、理由ごと残す。** やらなかったことも残します。同じ検討を二度しないために。
- **事故は、症状ではなく形を直す。** 番号がぶつかったら採番を1文にする、二重に鳴ったら書き手を1つにする。エラーを握りつぶす修正はしません。
