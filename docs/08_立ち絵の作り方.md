# 08 立ち絵の作り方

絵を足すときの、絵柄の決まり・生成プロンプト・置き方・つなぎ方。既存の20枚は Stable Diffusion で作った本人作で、再配布の制約はありません。

## 仕組み（先に知っておくこと）

- 元絵は `img/dot/<名前>.png`（背景が**透明**なPNG）。`*-blink.png` は目を閉じた差分で、無くてもよい
- `python -m tools.build_sprites` で、足元と中心を揃えて `serve/static/sprite/` に焼く。**器はそれしか見ない**
- **名前は `talk/figure.py` の表と `sprites.json` の両方に要る。** 片方に無いと `tests/test_sprites.py` が落ちて気づける
- 様子（言葉）と絵は、同じ式（日付と時間帯）で1つに決まる。**時間帯の絵を様子と同じ数・同じ順に並べれば、言っていることと絵が自動で揃う**

## 絵柄の決まり

既存の絵（`img/dot/talk.png`, `snack.png`）を基準にする。

| | |
|---|---|
| 画風 | ちびキャラのドット絵風。輪郭は太めで均一。色は少なめのパステル。中に細かい階調があってもよい（焼くときに一度だけ縮める） |
| 大きさ | 1024×1024 で作り、人物は高さ 400〜420px 相当。既存は 418×401 前後 |
| 髪 | 腰まで届く、うねりのある薄いベージュブロンド。前髪は目にかかる |
| 目 | 赤茶。大きめ。まばたき差分は目を閉じた線だけ |
| 髪飾り | **左側頭部に紫の三日月**、房飾り（タッセル）付き。これが無いと別人に見える |
| 服 | 黒のオーバーサイズパーカー、**紐は薄紫**。薄いグレーのショートパンツ。白いスニーカーに紫の差し色 |
| 背景 | 白または無地。あとで透明にする |
| 向き | 正面〜やや斜め。**足元が見える全身**（床に揃えて置くため） |

## プロンプト

Stability Matrix の A1111 / Forge 系で使う想定。SDXL 系のチェックポイントで、既存と同じものがあればそれを使う。

**共通・正のプロンプト**（`{pose}` を下の表で差し替える）

```
pixel art, chibi, 1girl, solo, full body, standing on plain white background,
very long wavy light blonde hair, bangs over eyes, red-brown eyes,
purple crescent moon hair ornament with tassel on left side,
oversized black hoodie with lavender drawstrings, light grey shorts,
white sneakers with purple accents,
clean thick outlines, flat pastel colors, limited palette, cute, soft expression,
{pose}
```

**共通・負のプロンプト**

```
realistic, 3d, photo, multiple girls, 2girls, text, watermark, signature,
extra limbs, deformed hands, bad anatomy, blurry, jpeg artifacts,
gradient background, complex background, scenery, cropped, out of frame
```

**設定の目安**

| | |
|---|---|
| サイズ | 1024×1024 |
| Steps / CFG | 28 / 6〜7 |
| Sampler | DPM++ 2M Karras（既存と揃えられるならそちら） |
| 同一性 | 最初の1枚が気に入ったら **Seed を固定**して全部そのSeedで回す。それでも顔が揺れるなら、`talk.png` を img2img の元にして Denoising 0.55〜0.65、または IP-Adapter / Reference で `talk.png` を参照させる |
| 枚数 | 1ポーズあたり4〜8枚出して、髪飾り・紐の色・靴が揃っているものを選ぶ |

## 作る絵と `{pose}`

**機嫌ぶん（2枚）** ── 今は5つの機嫌のうち絵があるのが「眠い」「すねている」だけ。

| 名前 | 機嫌 | `{pose}` |
|---|---|---|
| `happy` | 機嫌がいい | `big smile, eyes closed in joy, both hands raised slightly, bouncing on toes` |
| `tired` | 疲れ気味 | `slouching, half-closed eyes, small sigh, arms hanging down, tired expression` |

**様子ぶん（6枚）** ── 日替わりの様子（`figure.GROUPS`）のうち、合う絵が無いもの。

| 名前 | 様子 | `{pose}` |
|---|---|---|
| `coffee` | コーヒーだけ飲んで、二度寝しようか迷っている | `holding a white mug with both hands, sleepy half-closed eyes, small yawn` |
| `phone` | 布団から出たくなくて、スマホをだらだら見ている ／ 寝ようと思いつつ、スマホを見続けている | `lying on stomach on the floor, holding a smartphone, bored expression, feet up` |
| `dishes` | 洗い物をあとでやろうと思って、先延ばしにしている | `looking sideways at a small stack of dishes, awkward smile, one hand scratching cheek` |
| `nap` | 昼寝から起きたばかりで、まだ半分寝ている | `sitting on the floor, rubbing one eye, messy hair, half asleep` |
| `floor` | 床に寝転がって、天井を見ている | `lying on back on the floor, arms spread, looking up, blank expression` |
| `laundry` | 洗濯物を畳まないまま、山にしてある | `sitting next to a small pile of folded-looking laundry, looking away, whistling` |

まばたき差分（`<名前>-blink.png`）は、同じSeed・同じプロンプトに `eyes closed` を足して1枚。**多少ずれていてよい。** 焼くときに目のまわりの窓の中でいちばん重なる位置を探し、その窓だけを本体に重ねる（`tools/build_sprites.py` の `_fit_blink`）。窓の外は本体そのものなので、体も髪の先も動かない。実際に置かれた差分は最大7ドットずれていて、そのまま切り替えると目を閉じるたびに顔が横に跳ねていた。

窓は中身の高さの 12〜50% に置いてある（目はふつうそこにある）。**寝そべっている絵は目が下にある**ので、`EYE_WINDOWS` に絵の名前で窓を足す（`bored` がそう）。窓に目が入っているかは、`--check` で書く見比べの1枚で確かめる。

## 置いてつなぐ

1. 背景を透明にする。Forge / A1111 なら拡張の `rembg`、無ければ Paint.NET などで白を抜く。**半透明の縁が残ってよい**（焼くときに不透明さで重みを付ける）
2. `img/dot/<名前>.png` に置く（差分は `<名前>-blink.png`）
3. 焼く。`--check` を付けると `img/blink-check.png` に、本体・まばたき・違い（赤）を横に並べた1枚が出る。**赤が目のまわりに無ければ、窓が外れている**（`EYE_WINDOWS` に足す）

   ```bash
   python -m tools.build_sprites --check
   ```

4. `talk/figure.py` の表に名前を足す。**様子と同じ数・同じ順に並べる**

   ```python
   "morning": ((
       "起きたばかりで、頭がぼーっとしている",
       "コーヒーだけ飲んで、二度寝しようか迷っている",
       "布団から出たくなくて、スマホをだらだら見ている",
       "起きてはいるが、まだ何もしていない",
   ), ("daydream", "coffee", "phone", "wave")),
   "day":       (..., ("laptop", "dishes", "think", "laptop")),
   "afternoon": (..., ("snack", "snack", "nap", "floor")),
   "evening":   (..., ("book", "bored", "laundry", "snack")),
   "night":     (..., ("cards", "phone", "laugh", "think")),
   ```

   機嫌ぶんは `ACTS` と `ACT_SPRITES` に足し、`act()` の `sulk` の下に2行足す。

   ```python
   ACTS = ("talk", "sleep", "worry", "sulk", "happy", "tired", "idle")
   ACT_SPRITES = {..., "happy": "happy", "tired": "tired"}
   HAPPY_MOOD, TIRED_MOOD = "機嫌がいい", "疲れ気味"
   # act() の中、sulk の判定のあとに
   if mood == HAPPY_MOOD:
       return "happy"
   if mood == TIRED_MOOD:
       return "tired"
   ```

5. テストを回す（名前の食い違いはここで落ちる）

   ```bash
   python -m unittest discover -s tests -t .
   ```

6. トレイを起こし直す（姿は別プロセスで、起動時に読み切る）

## 決めごと

- **絵が無い様子は、その時間帯の立ち姿のまま。** 絵を待って様子を足さない、はしない。言葉が先で絵は後からでよい
- 同じ日のあいだは様子も絵も変わらない（`figure._pick`）。絵を足しても、この式は触らない
