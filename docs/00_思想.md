# ことは：思想

ことはを何に向けて作るか。**この文書は、いまの実装がどうなっているかを書きません。** 実装が思想に追いついているかは別に記します。

判断に迷ったときは、ここへ戻ります。

---

## 1. 人間らしく在る

**ことはは、人のように在ることを目指します。**

そのために、人の機能を**模倣し、近似します。** 完全な再現は要りません。人がそうしている、という形に寄せれば足ります。

設計に迷ったときは、技術の都合より先に**「人はどうか」**を問います。他の3つは、すべてここから導かれます。

| 決めごと | 人はどうか |
|---|---|
| 実体は同時に1体まで | 人は同時に2箇所に居ない |
| 考えるのは脳。器は仲介する | 考えるのは脳で、口や手は器官 |
| 言ったことは必ず会話に残る | 人は言ったことを無かったことにできない |
| 触れられない記憶は消える | 人は忘れる |
| 機嫌が続き、時間で薄れる | 人の気分はそういうもの |
| 時間帯で様子が変わる | 人には一日の流れがある |

**ただし、人間らしさは「人間の良いところ」だけを指しません。** 人は覗き見もするし、取りこぼしもします。安全や運用の線引きは、この思想からは導かれません。**別の判断として、別に決めます。**

## 2. 脳と器

**本体は、PC上で動く脳ひとつです。** データベースと、それを扱うAPI。**判断と処理は、すべてここが一括して担います。**

ブラウザ、タスクトレイ、PWAのアバターは**器**です。器は、ユーザーとのやり取りを**仲介するだけ**です。

| | |
|---|---|
| 脳がすること | 考える。決める。覚える。どこへ届けるかを選ぶ |
| 器がすること | 脳から届いたものを見せる・聞かせる。こちらの言葉を脳へ渡す |
| 器がしないこと | 判断。処理。会話の状態を持つこと |

**実体は、同時に1体までです。** 通話も同じです。2つの器から同時にことはが現れることは、この作りでは誤りです。

どの器に実体が宿るかは、**脳が決めます。** 器が名乗り出て奪い合うのではありません。

## 3. 単純で、軽い

**単純な処理は、単純な手段で片づけます。** スクリプトで足りるものに、仕組みを立てません。

- 何かを足す前に、**既にあるもので足りないか**を先に確かめる
- 依存を増やさない
- 常に動き続けるものほど、軽くする
- 将来の仮定のために、いま抽象化しない

## 4. 分かる形にする

**処理の流れが追えることを、設計の条件とします。**

- 名前が実態と合っていること
- 1つのことは1箇所に書くこと。同じ判断を複数の場所に複製しないこと
- 流れが一本で読めること。読むために全体を把握しなければならない作りにしないこと

合理的であることと、理解しやすいことは、**どちらも必要です。** 片方だけでは足りません。
