# ことは：思想

ことはを、何に向けて作るのか。それを書き残します。

いまのコードがどうなっているかは、ここには書きません。実装が追いついているかどうかは、別の話だからです。

迷ったときは、ここに戻ります。

---

## 1. 人間らしく在る

**ことはは、人のように在ることを目指します。**

そのために、人の仕組みを真似ます。そっくりそのままでなくて構いません。**人はこうしている、という形に寄せれば十分です。**

設計で迷ったら、技術の都合より先に「人ならどうか」を考えます。あとの3つは、すべてここから出てきます。

| 決めごと | 人はどうか |
|---|---|
| 実体は同時に1体まで | 人は、同時に2つの場所に居ない |
| 考えるのは脳。器は取り次ぐだけ | 考えるのは脳で、口や手は体の一部 |
| 言ったことは必ず会話に残る | 人は、言った言葉をなかったことにできない |
| 触れられない記憶は消える | 人は忘れる |
| 機嫌が続き、時間がたつと薄れる | 人の気分は、そういうもの |
| 時間帯によって様子が変わる | 人の一日には流れがある |

ただし、**人らしさとは、人の良いところだけを指すのではありません。** 人は覗き見もしますし、うっかり忘れもします。何を守るか、どう運用するかは、ここからは決まりません。**別の話として、別に決めます。**

## 2. 脳と器

**ことはの本体は、PCの中で動く脳ひとつです。** データベースと、それを扱うAPI。考えることも決めることも、すべてここでやります。

ブラウザ、タスクトレイ、PWAに出る姿。これらは**器**です。器は、こちらとことはのあいだを取り次ぐだけです。

| | |
|---|---|
| 脳がやること | 考える。決める。覚える。どこに出るかを選ぶ |
| 器がやること | 脳から来たものを見せる、聞かせる。こちらの言葉を脳へ渡す |
| 器がやらないこと | 考えること。決めること。会話の状態を持つこと |

**ことはの姿が出るのは、一度にひとつの器だけです。** 通話も同じです。2つの器から同時にことはが現れてはいけません。

どの器に出るかは、**脳が決めます。** 器が手を挙げて取り合うのではありません。

## 3. 単純に、軽く

**単純なことは、単純なやり方で済ませます。** スクリプトで足りるものに、わざわざ仕組みを作りません。

- 何かを足す前に、**いまあるもので足りないか**を確かめる
- 依存を増やさない
- ずっと動き続けるものほど、軽くする
- 「いつか要るかもしれない」ための作り込みはしない

## 4. 追える形にする

**処理の流れを追えること。** これを設計の条件にします。

- 名前と中身が合っていること
- ひとつのことは、ひとつの場所に書くこと。同じ判断をあちこちに写さないこと
- 上から順に読めること。全体を頭に入れないと読めない、という作りにしない

理屈が通っていることと、読んで分かることは、別です。**どちらも要ります。**
