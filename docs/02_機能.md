## 会話（テキスト）

ブラウザの会話画面から送ると、Gemini（`gemini-3.5-flash-lite`）が返事を作ります。1往復ごとに、固定ルール・人格・いまの時刻と状況（機嫌・話題・信頼）・思い出した記憶と日記・習慣・直近の会話を組み立てて渡します。「いまの様子」は時間帯ごとに日替わりで（毎日14時に必ずおやつ、にはならない）、続きのある話題は「気になっていること」として分けて渡すので、そちらから「あれどうなった？」と聞いてきます。

- **Fast / Slow の2つの道**があります。短くて疑問詞のない発言は Fast（保護記憶だけを積む軽いプロンプト）、それ以外は Slow（意味検索までする）。Fast で足りないとモデルが判断したら `NEEDS_SEARCH` を返し、同じ往復のうちに Slow でやり直します
- 返事に付いた**内部タグ**（使った記憶・機嫌・話題・頼まれごと・取り消し・PC操作）は、本文から外してから画面に出します
- **生成に失敗した回に同じ発言を送り直すと、同じ往復の空いている枠に返事が入ります。** 同じ発言が2行並ばないようにするためです

## 会話（通話）

電話ボタンを押すと、ブラウザの音声認識で聞き取り、返事を声で返します。**サーバーから見ると、判断も記憶もテキストの会話と同じ**です。

- **言い終わった文から先に返します**（`POST /api/chat/stream`）。生成が終わるまで待たないので、最初の声が早く出ます
- 返事が0.4秒待っても来なければ、**間つなぎ**（「えっと…」）を挟みます。声が重ならないよう、間つなぎも本文も同じ行列に並べて鳴らします
- 読み上げは家の中の **AivisSpeech**（VOICEVOX互換）。止まっていても会話は続きます

## 記憶

### 覚える（整理）

会話が途切れてしばらくすると、裏の巡回が**まとめて記憶に変えます**。1回で最大20往復・20,000字ぶん、作る記憶は最大8件。

| 層 | 種類 | 触れられなければ消えるまで | 例 |
|---|---|---|---|
| **episode**（出来事） | event | 30日 | 「歯医者に行った」 |
| **semantic**（意味） | fact / preference / open_topic / procedure | 180日 | 「コーヒーは豆から淹れる」 |

記憶には**タグ**（名詞寄り・最大3個）が付き、想起の近道になります。同じ内容は `source_key` で重複しません。**人名（ことは・相手の呼び名）はタグにしません**（`retrieve.persona_names`）。どの発言にも出てくるので毎回当たり、同じ記憶が想起の枠に居座るためです（実測: 名前2つが全往復で命中し、同じ6件が固定で渡っていた）。

**ことはが主語の出来事は記憶にしません。** 「スープパスタを作っている」のような身体のあることを、ことはの発言から出来事として固着すると、作り話が記憶になり、次の返事の根拠になる循環ができます。ことはの発言は相手について分かったことの材料にだけ使い、ことは自身のことで残すのは本人が口にした好みや気持ちだけです（`prompts/consolidation_system.txt`）。日記も同じで、相手に聞いただけのことを自分がしたことにしません（`prompts/diary_system.txt`）。

### 夜に読み返す（整理の2段目）

日記を書いたあと、1日1回、**ここ1週間に確かめた記憶と、続きのある話（open_topic）すべて**を、ここ1週間の日記と見比べます（`memory/review.py`、`prompts/review_system.txt`）。人が寝ているあいだに出来事を古い記憶と結び直すのと同じ段です。やることは3つで、作ることはしません。

- **寄せる**: 同じことを言っている記憶を1つに。出どころ・タグ・繋がりは残す方へ移し、残す方の強さを足します
- **直す**: 日記と食い違う記憶を、日記に合わせて書き直します（座標は捨てて作り直し）
- **閉じる**: もう済んだ話題を事実（fact）に変えます。結末を書き足すこともあります

ピン留めは触りません。各4件まで。API は1日1回で、失敗した日はその日はもう試しません（`notify.log` に残ります）。`KOTOHA_REVIEW_ENABLED=false` で止められます。

### 思い出す（想起）

1往復ごとに、次の順で候補を集めて渡します。

1. **保護記憶**（ピン留め）── 常に渡す
2. **タグ命中** ── 発言と直近会話に、記憶のタグが含まれるか。**強い記憶が先**（同じ強さならよく使われたタグ順）。人名のタグは辞書から外して照らす
3. **意味の近さ** ── Ollama（`bge-m3`）でベクトル化し、類似度 × 強さの重み が 0.62 以上（実測の中央値から）。薄れた記憶は床ぎりぎりでは出ず、強い手がかりなら出る
4. **最近のエピソード** ── 直近ぶん

### 忘れる（記憶の強さ）

記憶は**強さ**を1つ持ちます（`memory/strength.py`）。日ごとに半分ずつ薄れ（半減期は層で違い、出来事は速く意味はゆっくり）、**床を切ると消えます**。思い出すたびに足され（返事の `[USED:]`、整理の再確認・訂正、画面で直したとき）、**間が空いてから思い出したほど大きく足されます**（間隔反復）。上限で頭打ち。

消える時刻は強さから導いて `expires_at` に書くので、忘却の道は前のままです。作ったばかりの記憶（強さ1）が触れられずに消えるまでが、設定の30日 / 180日。**忘却より先に控えを取る**ので、消えた直後の状態しか残らない、ということは起きません。

強さは想起の順位にも効きます。使うほど出やすく、放っておくほど強い手がかりが要る。これが「思い出せそうで出ない」の正体です。

画面から手で直す・ピン留めする・消すこともできます。

## リマインド（頼まれごと）

「明日の9時に歯医者だと言って」のように頼むと、返事に内部タグが付き、`reminders` に入ります。時刻が来ると、ことはのほうから言います。

- 時刻の読み替え（「明日の9時」→ 絶対時刻）は**モデルに任せます**。いまが何時かはプロンプトに入っているためです
- 預かった印（`Rm. 9/18 09:00 歯医者`）が返事の下に出るので、**いつで預かったか**が確かめられます
- **12時間より古くなったものは黙って畳みます**（PCを閉じていた間のぶんを、まとめて言われても困るため）。畳んだ件数は `data/notify.log` に残ります
- 言えなかったぶんは消えません。3回試して駄目なら、30分先の頼まれごととして**戻します**
- 頼まれごとは**通知の間隔を待ちません**（同じ巡回の朝の一言とは1通にまとめます）。「7時に起こして」を7時10分に言っても仕方がないためです

### 追いかける（返事が来るまで、諦めるまで）

言って終わりではありません。返事が要ることなら、ことはは**もう一度言う時刻を自分で入れます**（返事に `[REMIND:]` を付ける。頼まれごとを言っている回だけ許されます）。何分後にするか、何度まで言うか、いつ諦めるかは、用件の重さを見て本人が決めます。コードで決めているのは、際限なく続かないための上限（6回）だけです。

- 返事があれば（会話でも通知の「あとで」でも）、追いかけはそこで終わります。本人に頼まれたぶんは残ります
- 諦めるときは、そう口に出せます。それは履歴に残り、記憶整理が拾うので、翌日「昨日は起きなかったね」と言えます
- PCが動いているかを渡すので、席に居るのに「起きてる？」とは聞きません
- 押しつけないのも、何度も言うのも、叱るのも、相手のためを思ってのこと。どうするかはことはに任せています（`fixed_rules.txt`）

### 繰り返し（毎日・平日・休日・曜日）

「毎晩22時に薬を飲んだか聞いて」「仕事の日は朝7時半に起きてるか聞いて」「週末だけ9時に起こして」「月水金はゴミ出し」は、タグの3つ目に `毎日` / `平日` / `休日` / 曜日の組（`月水金`、`土日`）が付きます。「週末」「毎週月曜・水曜」のような書き方も、`月〜日` の並びに揃えて預かります。言い終わる（または寝ていて畳む）たびに、次に当たる日のぶんを入れ直します。「平日」「休日」は `work.json` と祝日表（`schedule.py`）で判断するので、朝の一言と「仕事の日」の認識が揃います。

### 取り消す

「頼まれごと」の画面から消せるほか、会話の中で「薬のはもういいよ」と言えば、ことはが判断して `[DROP: 番号]` で取り消します。消したものは `Rm. 取り消し …` の印で返事の下に出ます。消せるのは本人に頼まれたぶんだけで、ことはが自分で入れた追いかけは返事があれば勝手に消えます。

## 日記

日付が変わったあと（`KOTOHA_DIARY_HOUR` 以降の最初の巡回）に、前の日の会話と、言った頼まれごとを材料に、ことはが自分の日記を三〜五行で書きます（`prompts/diary_system.txt`）。1日1件、`diary` 表に入ります。

- **話さなかった日も1件**入れます（「この日は話していない。」）。空白の並びも様子のうちで、そこにはAPIを使いません
- PCが寝ていた日は、起きてから**1回の巡回に1日ずつ**さかのぼって書きます（最大7日。日記を書き始めた日より前はさかのぼりません）
- 書けなかったら `notify.log` に残し、**1時間おきに3回まで**試し直します（`jobs.DIARY_RETRY_SECONDS` / `DIARY_TRIES`）。それでも駄目ならその日は諦め、翌日にさかのぼって拾います。503が一度来ただけでその日の日記が飛び、夜の整理・翌朝の一言・会話に添える日記が丸一日欠けたことがあるためです（2026-09-22）
- 記憶（`memory_nodes`）とは別物です。記憶は「覚えておくこと」、日記は「その日がどんな日だったか」。全部を記憶に残さないための置き場です

見返し方は四つあります。

- **会話**: ここ3日ぶんの日記をプロンプトに添えます。だらしなさが続いている（起きない、返事をしない、頼まれごとを守らない、夜更かし）と分かったら、注意したり叱ったりしてよいことにしてあります。ただし「同じことを毎日は言わない。一度言ったらしばらく見守る」（`fixed_rules.txt`）
- **朝のひとこと**: 昨日の日記から今日に繋がる一言を添えます。話さなかった日は渡しません
- **想起**: 日記も記憶と同じ道で座標にし（`diary_vectors`）、発言に意味の近い日を最大2件（`KOTOHA_DIARY_RECALL_LIMIT`）添えます。「先月の引っ越しどうだった？」に、その頃の日記が「思い当たる日記」として並びます。毎回添えているここ数日ぶんは重ねて出しません。話さなかった日は座標にしません（何にでも近くなって枠を潰す）
- **画面**: 設定シートの「日記を読む」で、新しい順に読めます（`GET /api/diary`）

### 習慣（何となく覚えていること）

脳と同じ順です。日々の出来事は日記に残り、**7日ぶん以上**溜まったところで**週に一度**、ここ2週間の日記を読み返して（`prompts/habits_system.txt`）、「夜10時ごろに話しかけてくることが多い」「土曜の夜は出かけがち」のような習慣を最大6件、`habits` 表に固めます。

- 挙がったものは確かめ直し（`confirmed_at`）、新しいものは覚え、**挙がらなかったものは退きます**（`retired_at`。消さないが、口には出さない）
- 会話には毎回そっと添え、「合う場面でたまに触れる。当てにして決めつけない」ことにしてあります（`fixed_rules.txt`）
- 「日記を読む」画面のいちばん上に並びます

### 承認して試す、小さな変化

同じ週次呼び出しで、任意の成長候補を最大1件作ります。対象は朝の口調、返事の簡潔さ、暇な時間のタブレットへの好みだけ。モデルの自由文で人格やコードは書き換えません。直近14日・最大40件の相手の短い発言から、別の日の2件以上を原文引用できることを検証します。自分の日記や自己観察だけを根拠にせず、材料がなければ提案しません。

候補は次の通常の会話の末尾で一度だけ尋ねます。静かな同席中は尋ねません。直後の限定した肯定表現、または提案ID付きの「一週間試す」で適用。話題が挟まった同意や曖昧な返事は適用しません。7日で試用の効果が切れ、以前の設定に戻ります。「これからも続ける」で保存でき、保存後も「元に戻す」で取り消せます。未承認の提案も7日で期限切れ。根拠・変更内容・承認と操作の時刻は `app_state` に保存します。

習慣抽出の出力の後に任意の候補を置き、候補の型不正や途中切れだけで、完結している習慣を失わないようにしています。呼び出し回数は増やさず、週次専用の出力上限を `KOTOHA_HABITS_MAX_TOKENS` で指定します。

## 器で暮らす

設定の「この器の役割」で会話画面を登録します。デスクトップの姿は最初からPCです。登録内容は既存の器IDに紐づいてPC側に保存され、ブラウザの保存領域を消した場合は再登録します。

| 器 | 役割 |
|---|---|
| 家に固定したPC | 寝床・作業のそば |
| 家に固定したタブレット | 暇な時間の居場所。額縁表示を選べる |
| iPhone | 持ち歩く器。自律移動の対象外 |
| 未登録の会話画面 | 従来どおり、呼ばれたときに話す |

現在地・移動時刻と理由・移動元・最後に表示の連絡があった時刻を会話に添えます。話題と機嫌は器ごとに分けません。接続や表示から在席や不在理由を断定せず、不在だけで機嫌・信頼を下げない材料として扱います。

自律移動は固定PCとタブレットの間だけです。既存の睡眠時間帯、または既存の機嫌が「眠い」のときにはPC、それ以外の暇な時間はタブレットを優先します。会話・通話・静かな同席中には移りません。最後の会話・移動・手動の呼び出しからそれぞれ30分空け、Webの移動先は90秒以内に表示の連絡があったものに限ります。数値は往復を避ける保守的な初期値で、実測による最適値ではありません。移動先が使えなければ留まります。

離れた器には、実際の移動先と理由を時刻付きの置き手紙として1枚残します。24時間または本人の帰還で非表示。専用の文章生成や追加通知はありません。額縁は同じ姿・時計・発言を見せ、本人がいないときは置き札を見せます。入力欄と電話ボタンは額縁にも残るので、そのまま話しかけたり通話したりできます（[04 フロントエンド](04_フロントエンド.md)）。**額縁を表示しているだけではスマホ通知を止めず、直近2分に操作されたときだけ見られていると扱います。** 画面の点灯維持・OSの全画面制御・常時音声待ち受けは行いません。

### 静かな同席

「少し作業するね」「ちょっと作業するね」「しばらく集中するね」「静かにしてて」、または設定のボタンで1時間だけ開始。「終わった」「作業終わったよ」など、明確な終了かボタンで解除します。話しかけられれば返答します。雑談・後から思い出す発言・休憩や夜更かしの声かけは控え、頼まれた通知・朝のひとこと・障害通知は続けます。預かり中の雑談も持ち越してまとめて出しません。
- 同じ振り返りで**相手への信頼**（高い / ふつう / 低め と、その理由ひとこと）も確かめ直します。一度のことで大きく動かさず、前から一段ずつ。会話には「相手への信頼: 高い（頼まれごとを守っている）」と渡り、叱るかどうかの根拠になります

## 朝のひとこと（ブリーフィング）

朝、決めた時刻に1通だけ。**別々に鳴らすと通知が朝から3通になる**ので、材料を集めて1つにまとめます。

| 材料 | 取得元 |
|---|---|
| 空模様・傘・服装・気温差・気圧の下がり | [Open-Meteo](https://open-meteo.com/)（鍵不要） |
| 今日のゴミ | `data/calendars/garbage.json`（自分で置く） |
| 今日の予定（祝日・全体会議） | `talk/schedule.py` の祝日表 ＋ `data/calendars/work.json` |
| 寝ているあいだの地震 | [P2P地震情報](https://www.p2pquake.net/)（鍵不要） |
| 頼まれごと | `reminders` |
| 暦の期限切れ | ゴミ・祝日・会議の日程が尽きるとき |

その時刻にPCが寝ていたら、起きたときに出します（ただし遅れすぎたら黙ります。夕方に「おはよう」と言われても困るため）。

朝に取れた空模様は、その日のあいだ覚えておきます（`weather.remember` → `app_state.sky_today`）。昼の会話にも「外の様子: 雨、最高21℃、傘はいる」の1行が状況に添わるので、持ち主と同じ空の下で話せます。外へ取りに行くのは朝の1回だけで、取れなかった日はその行が無いだけです。

## 通知

**言わずに鳴らすことはありません。** 自発的な発言はすべて履歴に残り、その本文がそのまま通知になります。開いても何も無い通知ほど不親切なものはないためです。

- 届け先は**姿が見えていればふきだし、でなければスマホ**（OneSignal）。どちらか一方だけが通ります
- 前の通知から間が空いていなければ（既定10分）、鳴らさずに**預かって**、あとでまとめて1通にします
- 通知に「あとで」ボタンが付きます（Safari では出ないので、iPhone では開いた画面から押します）
- **本文を通知に載せるかは設定で選べます。** 載せると会話の中身が OneSignal を通ります

## ことはのほうから言うこと

| きっかけ | 中身 |
|---|---|
| 朝 | 朝のひとこと |
| 頼まれた時刻 | リマインド |
| 根の詰めすぎ | 同じアプリを長時間触り続けているとき |
| 夜更かし | 深夜に起きているとき（その晩に一度だけ） |
| 間が空いた | しばらく話していないとき、そちらから一声 |
| 後から思い出した | 会話中に「思い出せそうで出なかった」記憶（近さが床のすぐ下）を1つ預かり、会話が途切れて15分たったら「そういえば」と一言（1日1回。関係が薄ければ黙る） |
| 見張り | 音声エンジンやOllamaが落ちたとき、ディスクの空きが減ったとき |
| Claude Code | 頼んでいた作業が終わって返事待ちになったとき（5分未満の短いやりとりでは言わない） |

## デスクトップの姿

タスクトレイに常駐すると、画面の右下にことはの姿が出ます（`ctypes` で書いた枠なしウィンドウ）。時間帯と機嫌、返事のときの顔で絵が変わり（[12 姿の決まり方](12_姿の決まり方.md)）、話しかけると会話画面が開きます。運んだ先（サブディスプレイでも）を覚えていて、ふきだしはその画面の中で姿の上に出ます。**姿が出ているあいだにことはが何か言うと、通知ではなくふきだしで出ます。**

## PCの世話

「Ollama起こして」のように頼むと、決められた操作だけを実行します。**ことはが好きなコマンドを組み立てられる作りにはしていません**（`talk/actions.py` の表にあるものだけ）。何をしたかは必ず記録します。

PCの様子（CPU・メモリ・ディスク・前面のアプリ・つけっぱなしの時間）は見えていて、聞かれたら答えます。

**自分の様子も分かります**（`talk/myself.py`）。起き直したとき、どれだけ止まっていたか（30分未満のうたた寝は数えない）、起き直したら中身が変わっていたか、設定を変えられたか（声・通知・姿・朝のひとこと・見守り・声かけ・日記などのオン／オフ。設定シートから変えれば止めなくても気づく）。何が変わったかは分かりませんし、分からないと言います。状況の行に1日だけ1行渡すだけで、通知にはしません。触れるか触れないか、気にするかどうかは人格に任せます。人格の書き換えは拾いません。人は自分の性格が書き換わったことを知覚しないからです。

**Claude Code の様子も見えています。** どの場所で動いているか、作業を終えて返事を待っているか、途中で止まっているように見えるか。読むのは記録の末尾の種類と時刻だけで、頼んだ中身や書かれたものは読みません。頼んでいた作業が終わったら、ことはのほうから一声かけます。
