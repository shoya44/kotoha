# ことは：全体仕様

運用設定の数値は既定値です。変更は `settings.bat` から `.env` で行います。設定一覧は [README](../README.md#設定の変更) を参照してください。

現在のコードに基づく実装概要です。導入・起動手順は [README](../README.md) を参照してください。

## 目的と構成

Windows上で動く、1人用のテキスト会話AIパートナーです。名前は「ことは」。直近の会話と、会話から抽出した記憶を使って応答します。

| 項目 | 現在の実装 |
|---|---|
| 言語 | Python |
| 保存先 | ローカルSQLite |
| UI | CUI、FastAPIによるWebチャット（読み上げ・音声入力に対応） |
| LLM | Gemini APIのOpenAI互換エンドポイント |
| モデル | `GEMINI_MODEL` で指定。会話・記憶整理で共通 |
| 設定 | 環境変数とプロジェクト直下の `.env` |
| リモート接続 | start.batでTailscale Serveを開始し、HTTPS URLを開く。Tailscaleの導入・ログインは事前に必要 |
| 音声 | 読み上げはVOICEVOX互換エンジン。音声入力はブラウザのWeb Speech API |

## 記憶

| 区分 | 保存先・用途 |
|---|---|
| 作業記憶 | `messages` の直近会話 |
| エピソード記憶 | `memory_nodes` の `episode/event` |
| 意味記憶 | `memory_nodes` の `semantic`。事実・好み・継続話題・手続き |

タグ一致、記憶間の1段の接続、最近の出来事・継続話題から関連記憶を取得します。タグ一致では、よく想起されたものと最近使ったものを先に返します。保護記憶は別枠で取得します。検索はPythonとSQLで行い、埋め込みAPIは使用しません。

## 会話と整理

1. ユーザー入力を保存する。
2. 直近会話を取得し、Fast/Slowを判定する。既定はSlow。
3. 記憶を含むプロンプトを作り、Geminiで返答を生成する。
4. 返答、記憶の利用実績、返答が申告した機嫌を保存し、再固定化候補を控える。
5. 条件を満たした時、または手動操作で、別のAPI呼び出しにより記憶を整理する。

整理では新規記憶の抽出、接続の登録、既存記憶の再確認・本文更新を行います。会話中には記憶本文を直接書き換えません。

プロンプトには現在時刻のほか、前回会話からの間隔、その時間帯のことはの様子、直前までの機嫌を渡します。

## 保持と運用

- 新規エピソードの期限は根拠発言から30日、意味記憶は180日です。
- 想起・再確認・本文更新のたびに期限を延長します。短縮はせず、無期限のまま残っている記憶に期限を付けることもありません。
- 保護は自動削除を防ぎます。明示削除や整理による本文更新を禁止する機能ではありません。
- 会話原文の自動期限削除はありません。
- DBバックアップは24時間ごとの自動作成とコマンドでの手動作成があり、最新7件を保持します。忘却より先に取ります。
- 会話・記憶の一部はGemini APIへ送信されます。
- PCの停止・スリープ中はWebチャットにも接続できません。
