# ことは：AP仕様

運用設定の数値は既定値です。変更は `settings.bat` から `.env` で行います。設定一覧は [README](../README.md#設定の変更) を参照してください。

現在の関数・モジュール構成に基づく処理仕様です。

## モジュール

| ファイル | 役割 |
|---|---|
| `launcher.py` | 起動確認、Tailscale Serveの開始・設定検証、HTTPS接続確認後のブラウザー表示 |
| `cli.py` | CUI、管理コマンド、整理の起動判定 |
| `web.py` | HTTP API、Web内の排他制御、バックグラウンド処理 |
| `chat.py` | 会話の保存、プロンプト生成、返答処理 |
| `router.py` | Fast/Slow判定 |
| `retrieve.py` | 記憶の取得 |
| `consolidate.py` | 記憶整理・再固定化 |
| `db.py` | スキーマ、DB操作、忘却、バックアップ |
| `llm.py` | Gemini API通信 |

## 会話ルート

1. 最大turn_idに1を加え、ユーザー入力を保存・コミットする。
2. 直近メッセージを最大 `RECENT_TURNS × 2` 件取得する。文字数超過時は古い発言を除くが、最後の1件は残す。
3. 今回保存した入力と末尾の発言が一致する場合は、プロンプト内の二重記載を避けるため直近会話から除く。
4. Fast/Slowを判定し、記憶と固定ルール・人格・日時・今回の入力を組み立てる。
5. Geminiを呼び出し、返答内の `[USED:1,2]` 形式から利用記憶IDを取り出す。
6. 返答、会話時刻、記憶の利用実績、再固定化候補を保存する。

LLM失敗時も入力は残り、返答は保存されません。ユーザーが送り直すと新しいturn_idになります。同一ターンの再送・重複排除の仕組みはありません。

## Fast/Slow

既定の `KOTOHA_FAST_ENABLED=false` ではSlowです。有効時も、入力が40文字超、質問・過去参照・記憶操作の語を含む、または入力が登録済みタグと一致する場合はSlowになります。文字数は設定で変更できます。

Fastは保護記憶だけを取得します。返答の1行目が `NEEDS_SEARCH` なら同じターン内でSlowに切り替え、追加の生成リクエストを送ります。別モデルへの切替ではありません。

「覚えて」「忘れて」などの自然文はSlow判定の材料です。直接のDB操作コマンドとしては解釈しません。

## 記憶取得

| 取得元 | 件数上限 |
|---|---:|
| 入力・直近会話に含まれるタグに一致する記憶 | 40 |
| 上記候補から1段接続で取得する記憶 | 40 |
| 最近のエピソード・継続話題 | 10 |
| 保護記憶 | 5 |
| 最終的に渡す関連記憶（保護以外） | 6 |

候補はIDで重複を除きます。各取得元の順序に従って候補を追加し、最終件数を制限します。利用回数によるスコアリングや独立した「近道」検索はありません。取得には期限条件があります。

## 記憶整理

- CUI：起動時と返答後、未処理会話が10ターン以上なら実行。手動コマンドでも実行可能。
- Web：60秒ごとに確認。未処理会話が10ターン以上、または未処理会話があり最後の会話から300秒超経過すると実行。
- バッチ入力：最大20ターン・20,000文字。処理位置より後の `extractable=1` のメッセージを対象とする。
- 再固定化候補：控えてあるIDのノードを取得。未処理会話も候補ノードもなければAPIを呼ばない。
- 生成上限：1,500トークン。
- 新規ノード：最大8件。エピソード400文字、意味記憶200文字、タグ3個まで。
- 更新：最大4件。本文と確認時刻を更新し、出典を追加、タグ利用回数をリセットする。
- 再確認：指定ノードの確認時刻を更新する。

新規・更新ノードの根拠IDは今回のバッチ内のメッセージに限定します。成功時に処理済み位置と整理時刻を更新し、再固定化候補を空にします。期限の延長、既存ノードの自動統合、承認待ちキューはありません。

## 排他制御とメンテナンス

Webの会話処理とバックグラウンド処理は、同じプロセスのthreading.Lockを共有します。別プロセスで起動したCUIや管理コマンドとの排他制御にはなりません。

CUIは終了時にメンテナンスを実行します。Webは最終忘却時刻から24時間超を条件としますが、その時刻が未設定なら条件を満たしません。Webのバックグラウンド処理の例外は現在表示されません。
