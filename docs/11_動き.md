# 11 動き

立ち絵を「生きている」ように見せる仕組み。**絵は止まったコマの束で、動きは器が作る。**

> 器の側（散歩・所作・跳ね・呼吸）は実装ずみ。`fidget_*` は本人 LoRA で24枚、`walk` は2周目で置いた（2026-09-23）。動きの間は 2026-09-24 に広げた（所作 2〜5分、散歩 5〜12分）。30〜90秒だと、机の端で始終そわそわしているように見えたため。

## 誰が何を決めるか

| | 決めるもの | 決めないもの |
|---|---|---|
| 脳（`talk/figure.py` → `serve/hub.py`） | いまの姿（絵の名前）と振る舞い（`act`: idle / talk / sleep / doze / worry / sulk / happy）、いまは合わない所作（`fidgets_off`）。表は [12 姿の決まり方](12_姿の決まり方.md) | 動きの間、どちらへ歩くか、どの所作を出すか |
| 器（`mascot/`・`static/app.js`） | 呼吸・まばたき・暇なときの動き（散歩・所作・跳ね） | どの姿を出すか |

まばたきが最初からそうだったように、**動きは器の癖**であって、脳のメッセージは増やしていない。脳が姿を替えたら、器は動きの途中でもやめて従う。

## 器が作る動き

| 動き | いつ | どう見えるか | 素材 |
|---|---|---|---|
| 呼吸 | 常に | トレイ: 1ドット縮む（足元は動かない）。会話画面: `scaleY(.994)`。**速さは絵ごと**: 寝ている絵（sleep / nap / doze）は 4.6〜5.2 秒、はしゃぐ絵（happy / laugh）は 2.6 秒、ほかは 3.4 秒（`BREATH_BY_NAME`。トレイと app.js に同じ表） | なし |
| 小さな動き | 暇なとき、揺れ・首かしげがそれぞれ 40〜120 秒おき（合わせて 20〜60 秒に一度ほど） | 絵は替えない。**揺れ**: 脚より上を右・戻す・左・戻す（2.4 秒）。**首かしげ**: 首より上（`NECK` = 48%）を片側へ1ドット（2 秒）。会話画面は `translateX(1px)` / `rotate(1.2deg)`。所作の間を広げたぶんを、これで埋める（2026-09-24） | なし |
| まばたき | 4〜10秒おき | 130ms だけ目を閉じた差分に替える | `<名前>-blink.png` |
| 跳ね | 話したとき、機嫌が「いい」に変わったとき | 足元から 6 ドット浮いて戻る（0.36秒）。機嫌がいいときは2回 | なし |
| 所作 | 暇なとき 2〜5 分おき | `fidget_*` の絵を 3.2 秒だけ出して戻る。脳が「いまは合わない」と言ったもの（時間帯・季節・機嫌）は除く | `fidget_*.png` |
| 触られたとき | 押された瞬間 | `surprised` の絵を 0.9 秒だけ出して戻る（暇でなくても出す）。会話画面は絵と一緒に少し縮む | `surprised.png`（無ければ跳ねるだけ） |
| 口パク | 声を出しているあいだ（会話画面だけ） | 260ms ごとに口を開けた差分と本体を交互に出す（速いとパクパクして違和感がある）。そのあいだはまばたきしない。差分の無い絵は口が動かないだけ | `<名前>-mouth.png`（いまは think / surprised） |
| 切り替え | 姿（絵の名前か向き）が替わる瞬間、常に | 前の絵から次の絵へ 0.2 秒で溶かす（クロスフェード）。トレイは 5 段、会話画面は前の絵の写しを重ねて薄くする。**まばたき・口パク・呼吸は溶かさない**（同じ姿の差分なので）。`surprised` は驚きらしく一瞬で替える。間のポーズの絵は作らない（組み合わせぶん要る上に、生成でも安定しない）。長くすると腕や小物の違う姿のあいだで二重写しに見える（2026-09-24） | なし |
| 散歩 | 暇なとき 5〜12 分おき（トレイだけ） | `walk` の絵で 60〜220 ドット横に歩く。足のコマがあれば 0.26 秒ごとに替え、無ければ一歩おきに **脚の帯を左右へ1ドットずらし**、1 ドット浮かせる（足踏みに見える）。絵が向いていない側へ行くときは返す（いまの `walk.png` は左向き）。画面の端で止まる。歩いた先を置き場所として覚える | `walk.png`（コマ `walk-f1.png` 〜は任意。**脚の窓の塗り直しでは足が動かなかった**ので、いまは本体だけ） |

動きの本体は `mascot/motion.py`（下の「動きを足す」）。「暇」の定義（`mascot/__main__.py` の `_idle`）: 実体がこの器にあり、脳に繋がっていて、返事待ちでなく、`act` が idle か happy で、ふきだしが出ておらず、掴まれていない。話している・寝ている・すねているときは動かない。

## 動きの作り方（行の帯をずらす）

呼吸・揺れ・首かしげ・足踏みは、どれも `sheet.Frame` の「行の帯を横に1ドットずらした同じ絵」で作る（`Frame.shifted(上, 下, dx)`、呼吸だけは `squashed()` で1行抜く）。行単位のコピーだけなので速く、一度作ったら持っておく（`_variants`）。絵は増やさない。境は `sheet.SEAM`（脚、72%）と `sheet.NECK`（首、48%）の2つ。

帯の外は動かず、はみ出た1列は捨てる。

## 動きを足す（`mascot/motion.py`）

**1つの動きは1つのクラス。** 器（`__main__.py`）は「どれかを始めて、終わったら片づける」しかしない（`motion.Idle`）。以前は `draw()`・`_move()`・`_stop_motion()` に種類ごとの分岐があり、1つ足すと3か所を触り、忘れると「終わらない動き」や「間が更新されない」になった（2026-09-24 に改めた）。

足すときは `motion.py` にクラスを書いて `MOTIONS` に並べるだけ。並び順が優先（先に書いたものから試す）。

```python
class Nod(Motion):
    kind = "nod"                # 名前。重複しない
    gap = (20.0, 60.0)          # 終わってから次に始めるまでの間（秒）
    length = 1.0                # 続く長さ（秒）。None なら advance() で自分で終える（Stroll がそれ）

    @classmethod
    def begin(cls, me, now):    # 始められるなら実体。素材が無いなら None（Stroll / Fidget がそれ）
        return cls(now)

    def shift(self, now):       # 行の帯のずらし (上, 下, dx)。無ければ None
        return (0.0, sheet.NECK, 1)
```

持ち替えられるもの（どれも省いてよい）:

| 手 | 何を答えるか | 使っている動き |
|---|---|---|
| `picture(base)` | 出す絵の名前。None なら脳の絵のまま | Stroll（walk）・Fidget（fidget_*） |
| `tag(me)` | 絵のコマ（歩きの足など） | Stroll |
| `mirror()` | 左右を返すか | Stroll |
| `shift(now)` | 行の帯のずらし | Stroll（足踏み）・Sway・Tilt |
| `breathes()` | そのあいだも呼吸するか | Stroll（止める） |
| `lift()` | 足元から浮かせるドット | Stroll（一歩おきに1） |
| `advance(me, now)` | 1ティック進める。False で終わる | Stroll（距離か画面の端） |
| `end(me)` | 片づけ | Stroll（歩いた先を覚える） |

**直し忘れは `tests/test_motion.py` が捕まえる**: `MOTIONS` に並べたものは、名前が重複せず、間が正の範囲で、長さがあるか自分で終われて、偽の器で始められて、見え方を答えられなければならない。

会話画面（`app.js`）は CSS の class を足す作りのまま（`avatar-sway` / `avatar-tilt` が例）。`scheduleMicro()` の候補に class 名を足す。

## 切り替えを溶かす（`mascot/fade.py`）

動きとは別の層。**器は毎ティック、出そうとしている絵とその鍵（名前, 向き）を `Crossfade.frame()` に通し、返ってきた絵を出す**だけ。鍵が替わった瞬間から 0.2 秒、前に出していた絵から新しい絵へ溶かした絵が返る（`sheet.Frame.blended`。不透明さを掛けた並びどうしなので、そのまま足し合わせてよい）。鍵が同じなら（まばたき・呼吸・帯のずらし）素通し。溶かす途中に鍵がまた替わったら、**見えている混ざった絵**から次へ向かう。

- 溶かさない絵は `fade.INSTANT`（いまは `surprised`）。名前を足すだけ
- 時計が止まるところ（出ていく前の手振り `wave_goodbye`）は `cut()` してから描く。見ていた絵を忘れるので次の姿はそのまま出る
- 混ぜる絵は持ち回らない（素材のぶんだけ増えるため）。1枚 1ms ほどで、40ms の時計に十分収まる
- 動き（`motion.py`）・絵の名前・脳のメッセージは知らない。**動きや絵を足しても、ここは触らなくてよい**

会話画面は `app.js` の `crossfade(image, src)`。本体の img は1枚のまま、**前の絵の写し（`.avatar-ghost`）を上に重ねて薄くする**。まばたき・口パクのように src を直接触るところは、何も知らずに今までどおり動く。`showPicture(name, { fade: false })` で溶かさずに替えられる（触られたときがそれ）。`prefers-reduced-motion` なら溶かさない。

**直し忘れは `tests/test_fade.py` が捕まえる。**

## 調整のつまみ

散歩・所作・揺れ・首かしげの値は `kotoha/mascot/motion.py`（各クラスの `gap` / `length` と先頭の定数）。呼吸・跳ね・触られたときは `kotoha/mascot/__main__.py` の先頭の定数。切り替えの溶かしは `kotoha/mascot/fade.py` の `SECONDS` / `STEPS` / `INSTANT`。会話画面は `static/app.js` の `FIDGET_*` `MICRO_*` `BREATH_*` `REACT_*` `MOUTH_MS` `FADE_*` と `style.css` の `avatar-breathe` / `avatar-hop` / `avatar-sway` / `avatar-tilt` / `avatar-ghost`（transition の長さは `FADE_MS` と揃える）。

| 定数 | 意味 |
|---|---|
| `Stroll.gap` `Fidget.gap` `Sway.gap` `Tilt.gap` | それぞれの間（秒）。終わってから次までの範囲 |
| `Fidget.length` `Sway.length` `Tilt.length` | 続く長さ（秒） |
| `STROLL_PX_MIN, STROLL_PX_MAX` | 一度に歩く距離 |
| `STROLL_SPEED` | 1ティック（40ms）に進むドット |
| `STROLL_BOB` | 歩くとき一歩おきに浮くドット（コマが無いときの歩き） |
| `WALK_FACES_RIGHT` | 歩きの絵が右を向いているか。いまの `walk.png` は左向きなので `False`。絵を描き直して向きが変わったらここを直す。合っていないと**両方向とも後ろ歩き**になる（2026-09-24 に直した） |
| `HOP_SECONDS, HOP_HEIGHT` | 跳ねの長さと高さ |
| `STROLL_STEP_DX` | 歩くとき脚の帯をずらすドット（0 で止める） |
| `BREATH_BY_NAME` | 絵ごとの呼吸の周期（秒）。載っていない絵は `BREATH_SECONDS` |
| `sheet.SEAM, sheet.NECK` | 脚と首の境（上からの割合） |
| `IDLE_ACTS` | 動いてよい振る舞い |
| `REACT_NAME, REACT_SECONDS` | 触られたときの顔と、出している長さ |

## 素材の作り方

歩きのコマは、本体を元に**脚の窓だけを描き直す**（[08 立ち絵の作り方](08_立ち絵の作り方.md)）。上半身は本体と同じ画素なので、コマを替えても顔が跳ねない。まばたきと同じ考え方。

コマを増やすなら `poses.py` の `frames` にタグを足す。`f3`, `f4` … と番号を続ければ、`build_sprites` が拾って `sprites.json` の `frames` に並べ、トレイは並び順に回す。

所作を増やすなら `fidget_` で始まる名前で1枚足すだけ。器は名前で拾うので、コードは触らない。出しどころを絞りたいときだけ `figure.FIDGET_FIT` に1行足す。

## やらないこと

- **脳に動きの指示を持たせない。** 「歩け」「跳ねろ」を脳が言い始めると、器ごとに出来ることが違うぶん、食い違いが増える。器はある素材で出来る動きだけをする
- 会話画面では歩かない。枠の中で横に動くと落ち着かないし、iPhone では画面が狭い
- 生成 AI にコマ送りの動画を作らせない。同一性が保てない。**止まった絵と、器の側の動き**で足りる
