# ことは

PCの中で暮らしている話し相手です。同じPCの中に記憶を持ち、時々そちらから話しかけてきます。

依存は3つ（httpx / fastapi / uvicorn）。Windows で動きます。言葉は Gemini（`gemini-3.5-flash-lite`）が作り、意味の近さは家の中の Ollama（`bge-m3`）が測り、声は AivisSpeech が出します。どれも無ければ無いなりに動きます。

## できること

| | |
|---|---|
| **話す** | ブラウザの会話画面から。外からは Tailscale 経由で同じ画面を開きます。iPhone ではホーム画面に置くと PWA として動きます |
| **通話する** | 電話ボタンで、聞き取りと読み上げ。**言い終わった文から順に喋ります** |
| **覚える・忘れる** | 会話が途切れたころに、まとめて記憶へ。記憶には**強さ**があり、使うほど残り、放っておくと薄れて消えます。大事なものはピン留め |
| **思い出す** | 発言に合わせて記憶を引きます。薄れた記憶は強い手がかりが要り、出なかったものは間が空いてから「そういえば」と言います |
| **日記を書く** | 日付が変わると、その日を三〜五行の日記に。翌朝の一言と会話で振り返り、「先月どうだった？」にはその頃の日記が添います |
| **習慣を知っている** | 週に一度、日記から「夜10時ごろに話しかけてくる」「土曜の夜は出かけがち」を何となく覚え、たまに話題にします |
| **機嫌と話題が続く** | すねていてもそのうち戻り、さっきまでの話題は翌日の「昨日の続きだけど」まで届きます |
| **思い出させる** | 「明日9時に歯医者って言って」「毎晩22時に薬飲んだか聞いて」「週末だけ9時に起こして」。返事が無ければ、自分でもう一度言う時刻を決めます |
| **朝いちばんに教える** | 天気・傘・ゴミの日・今日の予定・昨日の日記・寝ているあいだの地震を、1通にまとめて |
| **通知する** | 家に居なくてもスマホへ。**言ったことがそのまま通知**になります |
| **姿を出す** | タスクトレイに常駐すると、画面の右下に立ち絵が出ます。時間帯と機嫌で絵が変わります。トレイのシングルクリックで姿（iPhone に居れば PC へ呼び戻す）、ダブルクリックで会話画面 |
| **PCの世話をする** | 様子を見ていて、聞かれたら答え、頼まれたら決められた操作だけします。Claude Code の作業が終わったら一声かけます |

どう「人間らしく」しているかは [01 コンセプト](docs/01_コンセプト.md)、脳のどこに当たるかは [09 解剖図](docs/09_解剖図.md) にあります。

## 始め方

ダブルクリックするのは **`kotoha.bat`（起動）** と **`kotoha-menu.bat`（それ以外）** の2枚だけです。引数は要りません。

| 順 | やること |
|---|---|
| 1 | **`kotoha.bat`** をダブルクリック ── Python環境がなければ「いまここで作りますか？」と聞くので Y。依存まで入ります |
| 2 | **`kotoha-menu.bat`** をダブルクリック → **5** ── Geminiの鍵と合言葉を入れます |
| 3 | もう一度 **`kotoha.bat`** をダブルクリック ── タスクトレイに常駐し、画面に姿が出て、会話画面が開きます。ログオン時に自動で上げるなら メニューの **6** |

動きを窓で見たいときはメニューの **2**。すでに常駐しているときに `kotoha.bat` をダブルクリックすると、会話画面だけが開きます。
コマンドで使うなら `kotoha.bat` の後ろに言葉を付けます（`kotoha.bat help` で一覧）。`scripts/` の中の bat は部品なので直接は実行しません。

Gemini の鍵は [Google AI Studio](https://aistudio.google.com/) で取れます。通知を使うなら [OneSignal](https://onesignal.com/) の登録も要りますが、無くても動きます。Ollama と AivisSpeech は入れてあれば起動時に起こします。

## 自分ぶんのファイル

**住んでいる場所や呼び名は、リポジトリに入っていません。** `data/`（git の外）に置きます。置かなければ、その話題が出ないだけです。

### 人格 ── `data/prompts/persona.txt`

`prompts/persona.txt` がひな形です（呼び名は「あなた」）。写して、名前や距離感を自分のものに直してください。置くと、そちらが優先されます。

> ⚠️ **ひな形のほうを直接書き換えないでください。** `prompts/` はリポジトリに入っているので、そこに書いた名前はそのまま公開されます。直すのは写したほう（`data/prompts/persona.txt`）です。

会話画面の「ことばを直す」も、**置いてあるほう**（効いている1枚）を書き換えます。

### ゴミの日 ── `data/calendars/garbage.json`

```json
{
  "area": "○○区 ××1〜3丁目",
  "source": "区のカレンダーのURL",
  "until": "2027-03-31",
  "weekly": {"0": "燃やすごみ", "1": "資源", "3": "燃やすごみ", "5": "プラスチック"},
  "monthly": {"4": ["燃やさないごみ", [2, 4]]},
  "breaks": [[[12, 24], [12, 31]], [[1, 1], [1, 10]]]
}
```

`weekly` は曜日（月曜=0）から品目へ。`monthly` は曜日から「品目と、出る週」へ（例は第2・第4金曜）。`breaks` は年末年始のように曜日どおりでない期間、`until` はそのカレンダーが使える最後の日です。**期限が切れると、ことはが朝に教えてくれます。**

### 仕事 ── `data/calendars/work.json`

```json
{
  "from": "10:00",
  "to": "18:00",
  "meetings": ["2027-04-16", "2027-05-21"]
}
```

祝日は公開情報なので `talk/schedule.py` に入っています。「平日」「休日」の頼まれごとも、この2つで判断します。

## 画面

```
合言葉 → 会話画面 ──歯車→ 設定シート（1段だけ潜る）
                          記憶 / 頼まれごと / 日記と習慣 / プロンプト / PCの様子 / 設定
```

- 送信欄の右が**電話ボタン**。押すと通話に入ります
- 返事の下に `Rm. 9/18 09:00 歯医者` と出たら、**その時刻で預かった**という印です。`（毎日）` が付けば繰り返し、`Rm. 取り消し` は会話の中で取り消したものです
- 記憶は一覧から直せます。**大事なものはピン留め**すると消えません
- iPhone ではホーム画面に置くと、アプリのように開けます（通知もそこから）

### 器の役割と、静かな同席

設定の **「この器の役割」** で、使っている画面を登録します。家に固定したPCは寝床・作業のそば、固定タブレットは暇な時間の居場所、iPhoneは持ち歩く器です。タブレットでは **「額縁表示」** を選ぶと、履歴を畳んで姿・時計・吹き出しを大きく表示します。入力欄と電話ボタンはそのまま残るので、額縁のまま話しかけたり通話したりできます。「履歴を見る」で会話へ、「額縁に戻る」で戻れます。画面を点灯し続ける機能や常時マイク待ち受けはありません。

自律移動は固定PCとタブレットの間だけで、会話や通話中は移りません。不在時間だけで機嫌や信頼を下げません。**「少し作業するね」** または設定の **「静かな同席」** で、1時間、自発的な雑談を控えます。「終わった」で解除できます。頼んだ通知は続きます。

週の振り返りで根拠が見つかったときだけ、小さな変化を提案します。提案直後の「そうだね」か **「一週間試す」** で試用し、期限後は元の設定に戻ります。続ける場合は **「これからも続ける」**、取り消す場合は **「元に戻す」**。既存の人格を自動で書き換えることはありません。詳しくは [機能](docs/02_機能.md) を参照してください。

## 設定

会話画面の歯車、`kotoha.bat settings`、`.env` の直接編集。どれも同じところを書きます。画面から変えたぶんは**すぐ効きます**。

とくに見ておきたいもの:

```
KOTOHA_WEB_TOKEN=            合言葉（空だと誰も入れません）
KOTOHA_LATITUDE=35.681       天気を見る場所（初期値は東京駅）
KOTOHA_LONGITUDE=139.767
KOTOHA_BRIEFING_HOUR=7       朝のひとことの時刻
KOTOHA_BACKUP_DIR=           控えのもう1本の置き場（空だとDBの隣だけ）
```

全項目は [.env.example](.env.example)、意味は [07 運用と設定](docs/07_運用と設定.md) にあります。記憶の強さや機嫌の半減期のように仮置きした値と、その見直し方は [10 気になる点と見直し手順](docs/10_気になる点と見直し手順.md) にあります。

> ⚠️ **控えの置き場は設定しておいてください。** ことはの本体は記憶なので、DBの隣に1本しかないと、ディスクが1枚壊れた日にすべて消えます。

## 構成

```
kotoha/
  clock.py      時計（1本。テストでは止めて進める）
  config.py     設定の読み込みと検査
  talk/         会話・人格・PCの様子・天気・地震・ゴミ・予定・暦の期限
  memory/       DB・固着（整理）・想起・強さ・ベクトル・日記・習慣・夜の整理・頼まれごと
  serve/        Webサーバー・器のとりまとめ・ことはからの発言・裏の巡回・声
    static/     会話画面（素のHTML/CSS/JS）
  mascot/       デスクトップの姿（ctypes と自前のPNGデコーダ）
  tray.py       タスクトレイ常駐
  launcher.py   起動と配信
prompts/        固定ルール・人格のひな形・整理／日記／夜の整理／習慣の指示
data/           DB・控え・自分ぶんのファイル（Git管理外）
docs/           資料
tests/          テスト（840件ほど・20秒ほど）
tools/          手元の検査（check）と、テストの時間計測
```

## テスト

```
python -m tools.check
```

CI と同じ2つ（pyflakes → テスト）を順に回します。外への通信は塞いであるので、本物のGeminiも通知も呼びません。push と pull request のたびに GitHub Actions でも同じものが走ります。
